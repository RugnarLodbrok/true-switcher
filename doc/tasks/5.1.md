# 5.1. Привязать существующее удаление и воспроизведение к `Pause`.

- По нажатию `Pause` выполнить последовательно:

  1. Взять последнее слово из истории вместе со всеми завершающими пробелами.
  2. Удалить слово и пробелы.
  3. Переключить раскладку существующим способом.
  4. Воспроизвести слово с пробелами.

- Историю сохранить: повторный `Pause` исправляет то же слово в следующую раскладку.
- При пустой истории только переключить раскладку.
- Сохранить обе ветки распознавания своей виртуальной клавиатуры: сначала пытаться установить `physical_path` через `with_phys`; при ошибке этого шага создать устройство без `physical_path` и использовать точное совпадение `name` с `true-switcher-keyboard`. Слушатель должен исключать своё устройство в обоих случаях.
- Условия ручного теста: остальные клавиши отпущены, во время исправления новый ввод не поступает.
- Обработка нового ввода и удерживаемых клавиш в этот шаг не входит;
