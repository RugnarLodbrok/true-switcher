# Задача 19. Автосвич по паттернам

Реализовано. Ручное тестирование в KDE Plasma остаётся открытым.

## Параметры конфигурации

- `auto_switch = false`.
- `auto_switch_sound = true`.
- `switch_rules = []` — список правил автосвича.

Каждое правило содержит ровно одну целевую раскладку и список регулярных выражений:

```toml
[[switch_rules]]
target = "us"
patterns = ['^/[a-z]']
```

- `target` — строка со строгим идентификатором раскладки XKB, например `us`, `gb` или `ru`. Коды языков вроде `en` и списки раскладок не допускаются.
- `patterns` — регулярные выражения, записанные в целевой раскладке.
- Для разных целевых раскладок задаются отдельные элементы `[[switch_rules]]`.
- Вариант XKB (например, `phonetic` для `ru`) отличается от идентификатора раскладки; отдельное поле `variant` в текущий формат не входит.
- Если в KDE несколько раскладок с идентификатором `target`, выбирать первую по порядку в настройках KDE и использовать её настроенный вариант при преобразовании.

### Ошибки конфигурации

Следующие случаи считаются ошибкой конфигурации: программа пишет ошибку в лог и завершает работу.

- Некорректное регулярное выражение в `patterns`.
- Недопустимый идентификатор XKB в `target`.
- Раскладка `target` отсутствует в настройках KDE.

## Поведение автосвича

- Автосвич работает при `auto_switch = true`.
- Проверять паттерны только после ввода символа. После Backspace проверку не выполнять.
- Правила проверять по порядку в `switch_rules`; применять первое совпавшее правило.
- Ручную смену раскладки обрабатывать так же, как смену фокуса или нажатие стрелок: сбрасывать историю ввода.
- Сохранить существующие границы слова: пунктуация входит в слово; пробел завершает слово, а Tab и Enter завершают слово и сбрасывают историю.
- Для каждого правила, у которого `target` совпадает с текущей раскладкой, проверка паттернов не нужна.
- Для остальных правил после каждого введённого символа вычислять, как выглядело бы текущее слово в раскладке `target`, и проверять этот результат по `patterns`.
- При совпадении с любым паттерном правила сразу исправлять текущее слово и включать раскладку `target`. Завершения слова или ввода разделителя не ждать.
- После автосвича продолжать проверять это же слово при вводе следующих символов. Правила с другим `target` могут повторно исправить слово в другую раскладку; правила с `target`, совпадающим с текущей раскладкой, по-прежнему пропускаются.
- Совпадение определяется самим регулярным выражением; обязательного сопоставления со всем словом нет. Для ограничения начала слова используется `^`.

### Звук и статистика

- Использовать существующий звук переключения. При автосвиче воспроизведение определяется `auto_switch_sound`, независимо от `manual_switch_sound`.
- Автоматические исправления записывать в таблицу статистики `switches`.
- Добавить в `switches` колонку `mode`: `0` — ручное исправление (`manual`), `1` — автоматическое (`auto`).

### Пример

Правило с `target = "us"` и паттерном `^/[a-z]`:

1. В русской раскладке пользователь вводит `.т`.
2. Предполагаемый результат в английской раскладке — `/n`, он совпадает с паттерном.
3. Программа сразу заменяет `.т` на `/n` и включает `us`.
4. Пользователь продолжает ввод в английской раскладке.

Слово `текст.т` не совпадает с этим паттерном после преобразования: символ `/` находится не в начале слова.
