# Задача 19. Автосвич по паттернам

Черновик.

## Параметры конфигурации

- `auto_switch = false`.
- `auto_switch_sound = true`.
- `patterns_to_en = []`.

## Поведение автосвича

- Автосвич работает при `auto_switch = true`.
- `patterns_to_en` содержит регулярные выражения, записанные в целевой английской раскладке.
- Если текущая раскладка — `en`, проверка `patterns_to_en` не нужна.
- При другой текущей раскладке после каждого введённого символа вычислять, как выглядело бы текущее слово в английской раскладке, и проверять этот результат по `patterns_to_en`.
- При совпадении с любым паттерном сразу исправлять текущее слово и включать английскую раскладку. Завершения слова или ввода разделителя не ждать.
- Совпадение определяется самим регулярным выражением; обязательного сопоставления со всем словом нет. Для ограничения начала слова используется `^`.

### Пример

Паттерн `^/[a-z]`:

1. В русской раскладке пользователь вводит `.т`.
2. Предполагаемый результат в английской раскладке — `/n`, он совпадает с паттерном.
3. Программа сразу заменяет `.т` на `/n` и включает `en`.
4. Пользователь продолжает ввод в английской раскладке.

Слово `текст.т` не совпадает с этим паттерном после преобразования: символ `/` находится не в начале слова.
