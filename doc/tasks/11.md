# Задача 11. Установка для нескольких пользователей (черновик)

Проработать, как адаптировать установку True Switcher для нескольких пользователей одной системы. Определить, какие части установки должны быть общими, а какие — настраиваться для каждого пользователя, и как должны работать запуск, права доступа и удаление.

Задача остаётся черновиком до уточнения требований и выбранного подхода.
