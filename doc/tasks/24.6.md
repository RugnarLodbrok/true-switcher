# Задача 24.6. Логирование

Сейчас события нажатия и отпускания клавиш постоянно выводятся в stderr, а завершённые слова — в stdout как последовательности кодов клавиш. Это может раскрывать ввод, включая пароли, и задерживать обработку событий.

Использовать `log` вместе с `env_logger`: распределить сообщения по уровням `error`, `warn`, `info`, `debug` и `trace`, чтобы управлять подробностью вывода. Нажатия, списки клавиш и слова выводить на уровне `trace`, без отдельной настройки. По умолчанию содержимое ввода не выводится.

Уровень логирования задаётся полем `log_level` в конфиге. Допустимые значения: `off`, `error`, `warn`, `info`, `debug`, `trace`; значение по умолчанию — `info`. Недопустимое значение считается ошибкой конфигурации. Переменная окружения `RUST_LOG` не переопределяет уровень из конфига.

До чтения конфига инициализировать логгер с уровнем `info`. После успешного чтения применить выбранный в конфиге уровень. Ошибку чтения конфигурации выводить на уровне `error`.

## Утверждённые уровни текущих сообщений

Распределение уровней приведено ниже. Содержимое ввода выводится только на уровне `trace`, как решено выше.

| Место | Сообщение | Уровень |
|---|---|---|
| `src/main.rs`: ошибки конфигурации и завершения | Ошибка конфигурации или завершение с ошибкой | `error` |
| `src/main.rs`: `Ready` | Программа готова к работе | `info` |
| `src/main.rs`: `SYNTHETIC erase`, `SYNTHETIC replay` | Этапы исправления | `debug` |
| `src/main.rs`: `skipping statistics` | Не удалось получить раскладку для статистики | `warn` |
| `src/input.rs`: `Cannot open` | Не удалось открыть устройство при поиске | `debug` |
| `src/input.rs`: `No accessible pointer devices`, `Cannot monitor pointer` | Нет доступных указателей или не удалось открыть указатель | `warn` |
| `src/input.rs`: `OPEN POINTER`, `OPEN` | Открытие устройства | `debug`; список удерживаемых клавиш — `trace` |
| `src/input.rs`: `ENTRY ... begin`, `ENTRY accepted` | Попытка и успешный вход в захват | `debug` |
| `src/input.rs`: `ENTRY ... recorded` | Список нажатий при входе в захват | `trace` |
| `src/input.rs`: `WAIT_RELEASES`, `WAIT_ORDINARY` | Ожидание отпускания клавиш и обычного режима | `trace` |
| `src/input.rs`: `EVDEV` | Событие клавиши | `trace` |
| `src/input.rs`: вывод результата `history.process` | Слова как последовательности клавиш | `trace` |
| `src/input.rs`: `SOURCE_WRITE` | Попытка и результат отправки события в устройство | `trace`; ошибку передавать вызывающему коду |
| `src/input.rs`: `GRAB`, `UNGRAB` | Захват и освобождение устройства | Успех — `debug`; ошибку сообщать на уровне вызывающего кода без дублирования |
| `src/input.rs`: `ROLLBACK begin` | Начало отката и список восстанавливаемых клавиш | Начало — `debug`, список клавиш — `trace` |
| `src/input.rs`: `CLEANUP begin`, `CLEANUP end` | Начало и конец очистки | `debug` |
| `src/input.rs`: ошибки `CLEANUP` | Ошибки отката, освобождения клавиш и устройств | `error` |
| `src/statistics.rs`: поток, очередь и база | Не удалось запустить поток или записать статистику | `error` |
| `src/statistics.rs`: `skipping statistics`, `skipping typing statistics` | Не удалось преобразовать слово для статистики | `warn` |
| `src/layout.rs`: `layout tracking` | Ошибка отслеживания раскладки с повторной попыткой | Первое сообщение — `warn`, при длительном сбое последующие — не чаще раза в минуту; восстановление — `info` |
| `src/layout.rs`: `cannot start layout tracking` | Не удалось запустить поток отслеживания | `error` |
| `src/sound.rs`: ошибки звука | Ошибка воспроизведения или недоступность звукового потока | `warn` |
| `src/output.rs`: ошибка `physical_path` | Используется запасной способ определения устройства | `warn` |
| `src/environment.rs`: `qdbus executable` | Путь к найденному `qdbus` | `debug` |
| `src/tray.rs`, `src/tray/menu.rs` | Ошибка регистрации трея или действия меню | `warn`; ошибка действия также показывается уведомлением |

Всё, что находится в `src/bin`, в рамках этой задачи не изменять. Форматирование слова в `src/history.rs` само по себе не является логированием.
