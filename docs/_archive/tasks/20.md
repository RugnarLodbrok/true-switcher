# Задача 20. Статистика печати

## Цель

Собирать частоты желаемых слов — окончательных вариантов, которые пользователь оставил после набора и возможного исправления раскладки.

## Требования

- Слово учитывать в статистике в тот момент, когда оно удалено из истории набора.
- Для каждого слова увеличивать его счётчик.
- Если пользователь не исправлял слово, учитывать его в набранном виде.
- Если пользователь исправил слово, учитывать исправленный вариант. Исходный вариант отдельно не учитывать.
- Одно вхождение слова учитывать один раз, когда оно покидает историю. Само исправление слова не увеличивает счётчик.
- При сбросе всей истории учитывать каждое находившееся в ней слово.
- Слово, полностью удалённое пользователем через `Backspace`, не учитывать в статистике.
- Перед учётом приводить текст слова к нижнему регистру. Пунктуацию сохранять: `Привет` и `привет` увеличивают общий счётчик, а `привет,` имеет отдельный счётчик.
- Если слово не удалось преобразовать в текст, пропускать его с записью причины в лог.
- Хранить счётчики в новой таблице существующей базы статистики, отдельно от таблицы `switches`.

## Таблица-счётчик

Таблица `typing_words`:

- `word` — текст слова, первичный ключ (`TEXT PRIMARY KEY`).
- `count` — число учтённых вхождений (`INTEGER NOT NULL`).

Поведение соответствует `defaultdict(int)`: отсутствующее слово имеет счётчик `0`; первое вхождение создаёт строку с `count = 1`, каждое следующее увеличивает `count` на единицу.

## Пример

1. Пользователь набрал `привет` без исправления.
2. При удалении этого слова из истории счётчик `привет` становится равен `1`.
3. Пользователь набрал `ghbdtn` и исправил раскладку, получив `привет`.
4. При удалении исправленного слова из истории счётчик `привет` становится равен `2`. Строка для `ghbdtn` из-за этого ввода не создаётся.
