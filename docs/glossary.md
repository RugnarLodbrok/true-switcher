# Glossary

## General

### `teach` / shift switch

Ручная коррекция по `shift+<switсh-key>`:
- Добавляет слово в learned-rules.toml
- если слово уже есть, увеличивает его счетчик

### `stroke`

Пара из кода физической клавиши (`evdev::KeyCode`) и флага нажатого Shift (`shift: bool`). Например, клавиша `,` с Shift и без него даёт два разных `Stroke`. Раскладка хранится отдельно в `WordStroke` и определяет, какой символ получится из `Stroke`.

## Word scoring

Скоринг слов используется как метрика для эвристики принятия решения авто-переключения.

### `trie`

 - На стартапе приложения, доступные словари собираются в trie, с добавлением узлов `␣` в конце слов.
 - в узлах хранятся значения `log_2(P)` для данного префикса. Конечные узлы за счет `␣` хранят скор слова целиком, без учета его как префикса для других слов
 - `T[word␣] <= T[word]`
 - `T[word] < 0` в силу свойств логарифма

#### обозначение

- `T[word␣]` - скор слова по словарю
- `T[word]` - скор префикса по словарю

### `trie2`

trie2 хранит веса построенные из learned-rules. Веса суммируются из learned-rules.toml, без логарифмов. Так же как в trie, в конечных узлах `␣`
используется как обученная поправка к словарному скору

#### обозначение

- `T2[word␣]` - счетчик слова в learned-rules
- `T2[word]` - сумма счетчиков по данному префиксу в learned-rules

### word delta-score / prefix delta-score / дельта-скор слова / dscore

Дельта-скор - разница скоров слова в альтернативной раскладке и в текущей. Слово дельта-скор или дскор означет `D[]` или `d[]` в зависимости от контекста

На примере пары раскладок us/ru

- `D[цщкв] = d[цщкв] + d2[цщкв]` - полный дельта-скор слова. Он участвует в принятии решения переключения
- `d[цщкв] = T[word] - T[цщкв]` - дельта-скор по словарю
- `d2[цщкв] = T2[word] - T2[цщкв]` - поправка или дельта-скор по learned-rules

Слово `word` есть в словаре, слово `цщкв` тоже, но с очень маленьким весом

- `T[цщкв] << T[word]`
- `d[word] > threshold > 0`


## Punctuation

Пунктуация - символы, которые определяются в конфиге
```toml
punctuation = '[`~<>\p{P}]+'
```

### strong punctuation / strong pnt

В зависимости от контекста:
- Stroke, который является пунктуацией во всех активных раскладках
- символ этого stroke в данной раскладке

### weak punctuation / weak pnt

В зависимости от контекста:
- Stroke, который является пунктуацией в одной доступной раскладке, и не-пунктуацией в другой
- символ пунктуации, такой что в данной раскладке все способы набрать этот символ являются weak pnt stroke

### semi-strong punctuation / semi-strong pnt

Символ пунктуации, который в данной раскладке можно набрать и через `strong pnt`, и через `weak pnt` - разными `stroke`
Понятие имеет смысл при индексации текстовых ключей в trie2, когда исходный Stroke неизвестен
