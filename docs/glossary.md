# Глоссарий True Switcher

### word score / prefix score / скор слова

Логарифм по основанию 2 от нормированной словарной частоты слова в одной раскладке, `log2(P)`. Пока слово набирается, `P` берётся для введённого префикса. На первом пробеле `P` берётся для точного слова.

### word delta-score / prefix delta-score / дельта-скор слова / dscore

Разность скоров слова в альтернативной и текущей раскладках, `log2(P_alt) - log2(P_current)`. Положительное значение говорит в пользу альтернативной раскладки. Если учитываются сохранённые примеры, к этой разности добавляется поправка `learned_alt - learned_current`.

### teach / shit switch

Ручная коррекция по shift+<switсh-key>, Добавляющая слово в learned-rules.toml


### strong punctuation / strong pnt

Пунктуация, которая остается пунктуацией во всех раскладках.

### semi-strong punctuation / semi-strong pnt

Символ пунктуации, который в одной и той же раскладке можно набрать разными `Stroke`. Хотя бы один из них даёт пунктуацию во всех участвующих раскладках (`strong pnt`), а хотя бы один даёт в одной из них символ вне пунктуации.

### weak punctuation / weak pnt

Символ пунктуации, который не является символом пунктуации в хотя бы одной другой раскладке (среди активных раскладок)

### Stroke

Пара из кода физической клавиши (`evdev::KeyCode`) и флага нажатого Shift (`shift: bool`). Например, клавиша `,` с Shift и без него даёт два разных `Stroke`. Раскладка хранится отдельно в `WordStroke` и определяет, какой символ получится из `Stroke`.
