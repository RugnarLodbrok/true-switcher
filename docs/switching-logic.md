# Как работает автосвич

`pattern_switch` включает свич по regex, `auto_switch` — по словарям. В трассах `␣` обозначает введённый пробел. [Что хранит `Stroke`](glossary.md#stroke)

Для примеров использованы словари `en_full.txt` и `ru_full.txt` из `dicts/content/2018`. С этими словарями в конфиге трассы можно получить командой:

```bash
printf '%s\n' 'ru us хшв2ъ' 'ru us .е 0' 'ru us куищще' 'us ru ult' \
  'us ru ,jkmit' 'us ru .git 0' 'us ru git' |
  true-switcher score --learned-rules false --threshold 15
```

`score` показывает текст в обеих раскладках и словарные скоры. Решения по regex в примерах следуют из `switch_rules`. Индекс `0` выбирает для точки клавишу `KEY_SLASH` в запросе `ru us .е 0` и `KEY_DOT` в запросе `us ru .git 0`.

## Паттерн-свич

Ввод начинается в RU. Оба regex проверяют текст в US. Для этих примеров словарный свич отключён.

```toml
pattern_switch = true
auto_switch = false

[[switch_rules]]
target = "us"
patterns = ['^\[[a-zA-Z\d]+\]$', '^/[a-z]+']
```

**Тег в квадратных скобках**

```text
Ввод в RU   Текст для regex в US   Решение
хшв2        [id2                   —
хшв2ъ       [id2]                  Свич в US → [id2]
```

**Начало пути `/tmp`**

```text
Ввод в RU   Текст для regex в US   Решение
.           /                      —
.е          /t                     Свич в US → /t
```

Для тега нужна закрывающая скобка. Для пути достаточно первой буквы после `/`, и после свича `mp` можно допечатать в US. Первый совпавший блок `switch_rules` для другой раскладки имеет приоритет перед словарём.

## Словарный свич

Включён `auto_switch`, совпадений по regex и записей в `learned-rules.toml` нет. У обоих словарей порог `15`. [Словарный скор и дельта-скор](glossary.md#word-scoring)

**Свич на префиксе `rebo`**

В RU начинают набирать `reboot`. В трассе первое `yes` появляется на `куищ`.

```text
Text (ru)  Text (us)  Score (ru)  Score (us)  Delta  Above threshold
к          r               -4.49       -5.75  -1.26  no
ку         re              -8.87       -6.89   1.99  no
куи        reb            -15.24      -13.84   1.39  no
куищ       rebo             -inf      -17.01   +inf  yes
```

Свитчер заменяет `куищ` на `rebo`. Оставшиеся `ot` набирают уже в US.

**Свич на первом пробеле после `ult`**

В US набирают `ult`. До пробела `score` сравнивает префиксы, на первом пробеле — слова целиком.

```text
Text (us)  Text (ru)  Score (us)  Score (ru)  Delta  Above threshold
u          г               -6.54       -6.00   0.54  no
ul         гд             -14.31       -9.10   5.21  no
ult        где            -14.85       -9.11   5.74  no
ult␣       где␣           -25.87       -9.25  16.62  yes
```

На первом пробеле дельта-скор вырастает с `5.74` до `16.62` и проходит порог. Свитчер заменяет `ult␣` на `где␣`.

Если `pattern_switch` включён и для текущей US настроено правило `^ult $`, оно блокирует этот словарный свич. Совпадение с правилом для RU по-прежнему имеет приоритет.

## Защита пунктуации и скоринг слов с пунктуацией в начале

Может случиться так что так что наивный скоринг покажет `delta >> threshold`, но это не будет ожидаемым поведением. Этот случай покрывается механикой `punctuation protection`.

Превышение порога не триггерит переключение, если в текущей раскладке весь токен состоит из пунктуации

Второй аспект этого механизма - скор слова считается дважды:
 - `T[.git]`
 - `T[git]`

Берется большее из двух значений 

```text
Text (us)  Text (ru)  Score (us)      Score (ru)   Delta  Above threshold
.          ю          T[.]   = -inf       -11.05    +inf  yes
.g         юп         T[g]   = -5.02      -17.05  -12.03  no
.gi        юпш        T[gi]  = -8.56        -inf    -inf  no
.git       юпше       T[git] = -17.44       -inf    -inf  no
.git␣      юпше␣      T[git␣]= -18.78       -inf    -inf  no
```

## Ручное обучение / `teach`

Пример ложного срабатывания

- в словаре 
  - `tls` встречается 10 раз
  - `еды` — 6552 раза
- Порог 10
- при вводе в `us` слова `tls` будет ложное срабатывание переключения

```text
Text (us)  Text (ru)  Score (us)  Score (ru)  Delta  Above threshold
t          е               -2.99       -5.54  -2.54  no
tl         ед             -17.97      -10.21   7.76  no
tls        еды            -25.36      -14.52  10.84  yes
tls␣       еды␣           -26.13      -14.53  11.60  yes
```

Нажатие `Shift + Pause`
 - исправляет `еды` обратно на `tls` 
 - добавляет единицу к счётчику `tls` в секции `[us]` файла `learned-rules.toml`
 - 1 будет добавляться к дельта-скору

```text
Text (us)  Text (ru)  Score (us)  Score (ru)  Delta  Learned  Result  Above threshold
t          е               -2.99       -5.54  -2.54       -1   -3.54  no
tl         ед             -17.97      -10.21   7.76       -1    6.76  no
tls        еды            -25.36      -14.52  10.84       -1    9.84  no
tls␣       еды␣           -26.13      -14.53  11.60       -1   10.60  yes
```

Еще одно такое же нажатие `teach` или ручное увеличение счетчика в `learned-rules.toml` даст желаемый результат

```text
Text (us)  Text (ru)  Score (us)  Score (ru)  Delta  Learned  Result  Above threshold
t          е               -2.99       -5.54  -2.54       -2   -4.54  no
tl         ед             -17.97      -10.21   7.76       -2    5.76  no
tls        еды            -25.36      -14.52  10.84       -2    8.84  no
tls␣       еды␣           -26.13      -14.53  11.60       -2    9.60  no
```
