# Задача 12. Пользовательская настройка клавиши переключения

Добавить пользовательский конфиг True Switcher с настройкой клавиши, которая запускает исправление слова и переключение раскладки.

## Расположение

Хранить конфиг в `~/.config/true-switcher/config.toml`. Это стандартный каталог пользовательских настроек Linux; путь доступен и инсталлеру, и системной службе, работающей от имени устанавливающего пользователя.

## Требования

- В конфиге задаётся клавиша, запускающая исправление слова и переключение раскладки. Значение по умолчанию должно сохранять текущее поведение — клавиша `Pause`.
- Имя клавиши задаётся кодом Linux input, например `switch_key = "KEY_PAUSE"`.
- Инсталлер создаёт каталог и конфиг с настройками по умолчанию, только если конфига ещё нет. Существующий конфиг не перезаписывается.
- Приложение читает пользовательский конфиг при запуске и использует заданную клавишу.
- Если конфиг отсутствует либо значение `switch_key` некорректно или не распознаётся, приложение молча использует `KEY_PAUSE`.
- Клавиша-модификатор, заданная в `switch_key`, запускает исправление при одиночном нажатии, когда остальные модификаторы отпущены.
- В конфиге добавить комментарий с командой `systemctl --user restart true-switcher-session.service` для применения изменений и примерами допустимых клавиш: `KEY_PAUSE`, `KEY_CAPSLOCK`, правые модификаторы (`KEY_RIGHTCTRL`, `KEY_RIGHTSHIFT`, `KEY_RIGHTALT`, `KEY_RIGHTMETA`), `KEY_SCROLLLOCK`, `KEY_MENU`, `KEY_F12` и `KEY_F13`.
- Не показывать уведомления об отсутствующем или некорректном значении клавиши в рамках этой задачи. Уведомления через иконку в системном трее вынесены в [задачу 13](13.md).
