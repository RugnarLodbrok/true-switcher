# Задача 18. Звук при ручном переключении

## Требования

- Добавить в `config.toml` булеву опцию `manual_switch_sound` со значением по умолчанию `false`.
- При `manual_switch_sound = true` сопровождать успешное ручное переключение раскладки коротким писком частотой 2 кГц.
- При `manual_switch_sound = false` звук не воспроизводить. Отсутствие опции в конфиге равнозначно `false`.
- Синтезировать звук в коде, без звуковых файлов.
- Все параметры звука для отладки хранить в отдельном TOML-файле, который читает только отладочная точка входа.
- В общем `config.toml` размещать только переключатель `manual_switch_sound`; параметры синтеза туда не добавлять.
- Для вывода звука использовать PulseAudio Simple API через Rust-привязки.

## Параметры отладочного звука

В отдельном TOML-файле задавать четыре параметра:

- `duration_ms` — общая длительность звука в миллисекундах.
- `frequency_hz` — частота в герцах; исходное значение — `2000`.
- `fade_in_ms` — длительность нарастания в миллисекундах.
- `fade_out_ms` — длительность затухания в миллисекундах.

## Вывод звука

Синтезированные PCM-сэмплы передавать в PulseAudio Simple API. С PipeWire работать через совместимый сервер `pipewire-pulse`. API блокирующий, поэтому на этапе 2 воспроизведение вынести из обработки клавиатурного ввода.

Установщик уже запускает системную службу с `User=` пользователя. Для подключения к его аудиосерверу нужно определить адрес сокета или передать подходящее окружение. Сейчас в unit задан `DBUS_SESSION_BUS_ADDRESS`, но не `XDG_RUNTIME_DIR`. На этапе 1 проверить доступ к звуку и из терминала, и в окружении службы.

Источники: [PulseAudio Simple API](https://freedesktop.org/software/pulseaudio/doxygen/simple.html), [совместимость PipeWire с PulseAudio](https://pipewire.pages.freedesktop.org/pipewire/page_man_pipewire-pulse_1.html).

## Этапы реализации

### Этап 1. Отдельная точка входа для отладки звука

- Добавить отдельную отладочную точку входа, которая только синтезирует и воспроизводит короткий писк частотой 2 кГц.
- Использовать её для совместной с пользователем отладки звучания и вывода звука.
- Параметры синтеза читать из отдельного TOML-файла для отладки. Длительность писка и остальные параметры звучания подобрать на этом этапе.
- Проверить подключение через PulseAudio Simple API из терминала и в окружении системной службы.
- Этап завершён, когда звук отлажен и результат согласован с пользователем.

### Этап 2. Интеграция с ручным переключением

- После завершения этапа 1 подключить отлаженный звук к ручному переключению.
- Подобранные на этапе 1 параметры звука закрепить в коде; отдельный TOML-файл оставить только для отладочной точки входа.
- Добавить опцию `manual_switch_sound` и обработку её значения по требованиям выше.
- Обновить пользовательскую документацию и проверить сценарии ниже.

## Критерии готовности этапа 2

- Опция описана в пользовательской документации с примером `manual_switch_sound = false`.
- При включённой опции одно ручное переключение вызывает один короткий писк частотой 2 кГц.
- При выключенной или отсутствующей опции переключение происходит без звука.
- Неудачная попытка переключения не вызывает писк.
