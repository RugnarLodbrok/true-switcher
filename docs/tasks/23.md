# Задача 23. Back off при удержании клавиши

## Идея

Сбрасывать историю ввода при длительном удержании клавиши. Такое удержание может указывать на игру или на ввод, который нельзя надёжно исправить переключением раскладки и который не требуется исправлять.

## Ожидаемое поведение

`Back off` — состояние, в котором история сброшена и обработка ввода приостановлена до отпускания всех клавиш.

Переходить в `back off` при любом из двух событий:

- получен первый автоповтор клавиши (`value=2`);
- клавиша удерживается дольше 300 мс, даже если автоповтора нет.

Время удержания отсчитывается отдельно для каждой клавиши на каждой клавиатуре.

Это правило действует для всех клавиш, кроме левого и правого `Shift`: в том числе для `Space`, цифрового блока независимо от `NumLock`, других модификаторов и клавиши исправления. Удержание клавиши исправления тоже может привести к отмене ожидающего исправления.

При переходе в `back off` сбрасывать историю, включая текущее и предыдущее слова. Накопленный до сброса ввод не должен использоваться для последующего исправления. Во время `back off` не накапливать историю и не выполнять исправление. Отпускание клавиши после длительного удержания также сбрасывает историю. Оставаться в `back off`, пока не будут отпущены все клавиши, включая модификаторы; после этого возобновить обработку ввода.

При сбросе истории передавать накопленные слова в статистику, как при обычном сбросе.

При переходе в `back off` отменять ожидающее исправление, включая ручное.
Это относится и к ожиданию отпускания других клавиш перед захватом клавиатуры. Уже выполненное исправление не откатывать.

`Back off` не должен мешать приложению получать нажатие, повторы и отпускание клавиши.

## Реализация и тесты

- [x] Переход по первому автоповтору и по таймеру без новых событий ввода.
- [x] Сброс обоих слов через обычный механизм записи статистики.
- [x] Отмена ожидающего ручного и автоматического исправления, включая вход в захват.
- [x] Ожидание отпускания всех клавиш на всех отслеживаемых клавиатурах.
- [x] Автоматические тесты переходов, отмены исправления и исключения для `Shift`.
- [x] Ручные тесты в KDE Plasma.

## Ручные тесты

1. Набрать два слова и удержать символьную клавишу до автоповтора. Приложение должно получить повторы; после отпускания клавиши исправление не должно использовать прежние слова.
2. Удержать без автоповтора `Ctrl`, `Alt`, `Meta` или клавишу исправления дольше 300 мс. После отпускания прежняя история не должна участвовать в исправлении.
3. Повторить удержание для `Space` и цифрового блока с включённым и выключенным `NumLock`.
4. Удерживать только `Shift` дольше 300 мс и продолжить печать. История должна сохраниться, исправление должно работать.
5. Вызвать `back off`, оставив зажатым `Shift` или клавишу на другой клавиатуре. Ввод до отпускания всех клавиш не должен накапливаться; после отпускания история должна начаться заново.
6. Запросить ручное исправление, удерживая другую клавишу. После первого повтора или 300 мс ожидания исправление должно отмениться.
7. Убедиться, что накопленные до `back off` слова учитываются в статистике однократно.
