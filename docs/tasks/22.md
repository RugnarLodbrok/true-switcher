# Задача 22. Исключения приложений для автосвича и статистики ввода (черновик)

## Идея

Отключать автосвич и запись статистики ввода, когда активно окно приложения из списка исключений. Основной сценарий — игры: ввод в игре не должен вызывать автоматическое исправление раскладки или попадать в статистику печати.

## Ожидаемое поведение

- Проверять приложение, которому принадлежит активное окно, по списку исключений.
- Пока активно окно приложения из списка, приостанавливать автосвич и запись статистики ввода.
- При переходе в другое приложение снимать эту приостановку.
- Ориентироваться на активное окно: само наличие запущенного приложения из списка не должно приостанавливать работу в других приложениях.

## Определение активного окна

Использовать Wayland-протокол KDE `org_kde_plasma_window_management` напрямую из приложения, без KWin Scripts. Получать события изменения активности окон и сведения для сопоставления приложения со списком исключений: `app_id` и PID.

В текущем сеансе KWin 6.8.2 обнаружен протокол версии 21. KDE считает этот протокол внутренней деталью окружения и предупреждает о возможных несовместимых изменениях; доступность и поведение нужно проверить на поддерживаемых версиях Plasma.

Источник: [описание протокола KDE](https://github.com/KDE/plasma-wayland-protocols/blob/master/src/protocols/plasma-window-management.xml).

## Требует обсуждения

- Формат списка исключений и правила сопоставления приложения, в том числе игр через Proton.
- Поведение ручного исправления в исключённых приложениях.
- Обработка истории набора при входе в исключённое приложение и выходе из него, чтобы ввод из него не попадал в статистику позднее.
- Поведение при недоступности протокола или отсутствии активного окна.
