# Установка

## Purpose

Установка и удаление службы для пользователя KDE Wayland.

## Requirements

### Requirement: Предварительные условия

True Switcher SHALL перед установкой проверять готовый release-бинарник, иконки, qdbus, сеанс KDE Wayland, systemd и целевые пути.

#### Scenario: Предварительные условия

- **WHEN** существует один из целевых файлов службы
- **THEN** установка останавливается до записи компонентов

### Requirement: Интеграция с сеансом

True Switcher SHALL устанавливать бинарник, иконки, правило Polkit и два systemd unit, включать и запускать пользовательскую службу.

#### Scenario: Интеграция с сеансом

- **WHEN** установка прошла успешно
- **THEN** системная служба работает от устанавливающего пользователя с дополнительной группой input, а пользовательский unit связывает её с графическим сеансом

### Requirement: Откат установки

True Switcher SHALL при ошибке запуска останавливать службы и откатывать установленные компоненты.

#### Scenario: Откат установки

- **WHEN** запуск службы после включения автозапуска завершился ошибкой
- **THEN** установщик отменяет автозапуск и удаляет созданные служебные файлы

### Requirement: Сохранение пользовательских данных

True Switcher SHALL создавать конфиг только при его отсутствии и сохранять пользовательские данные при удалении.

#### Scenario: Сохранение пользовательских данных

- **WHEN** пользователь запускает make uninstall
- **THEN** установщик удаляет компоненты службы и оставляет конфигурацию и статистику

### Requirement: Метка SELinux

True Switcher SHALL при доступной политике применять и проверять метку бинарника, если не задан TRUE_SWITCHER_INSTALL_SELINUX_SKIP=1.

#### Scenario: Метка SELinux

- **WHEN** проверка метки при обычной установке завершилась ошибкой
- **THEN** установка прерывается с откатом
