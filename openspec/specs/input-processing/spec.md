# Обработка событий ввода

## Purpose

Согласованная обработка физических устройств, состояния KDE и преобразования нажатий между раскладками.

## Requirements

### Requirement: События ввода

True Switcher SHALL сохранять порядок публикации событий клавиатур, фокуса, раскладки и жизненного цикла в общей очереди.

#### Scenario: События ввода

- **WHEN** событие опубликовано во время ожидания
- **THEN** читатель просыпается и обрабатывает его без ожидания следующего физического нажатия

### Requirement: Протокол захвата

True Switcher SHALL при использовании режима с grab дожидаться отпускания обычных клавиш и освобождать уже захваченные устройства при сбое. При откате входа в захват True Switcher SHALL восстанавливать скрытые нажатия текстовых клавиш нумпада через исходные устройства.

#### Scenario: Протокол захвата

- **WHEN** захват второй клавиатуры завершился ошибкой
- **THEN** первая клавиатура освобождается с восстановлением скрытых событий согласно их исходному устройству

#### Scenario: Нажатие Numpad Equal скрыто при входе в захват

- **WHEN** пользователь нажимает Numpad Equal на уже захваченной клавиатуре во время входа в захват и попытка откатывается
- **THEN** True Switcher восстанавливает нажатие через эту клавиатуру в ходе отката

### Requirement: Раскладка KDE

True Switcher SHALL отслеживать исходную раскладку и её изменения через сессионный D-Bus.

#### Scenario: Раскладка KDE

- **WHEN** служба раскладок повторно появилась после потери владельца
- **THEN** наблюдатель восстанавливает подписку и запрашивает актуальную раскладку

### Requirement: Преобразование XKB

True Switcher SHALL преобразовывать нажатия по сохранённым name, variant, model и options с учётом Shift и переиспользовать успешно скомпилированную карту в пределах потока.

#### Scenario: Преобразование XKB

- **WHEN** конвертация для одной из целей regex завершилась ошибкой
- **THEN** частичный текст не используется, проверка продолжается со следующей целью

### Requirement: Уровень логирования

True Switcher SHALL читать log_level из конфигурации с уровнем info по умолчанию.

#### Scenario: Уровень логирования

- **WHEN** пользователь задаёт неподдержанное значение уровня
- **THEN** значение отклоняется как ошибка конфигурации
