## ADDED Requirements

### Requirement: Приостановка автосвича при движении мыши

True Switcher SHALL приостанавливать автосвич при движении мыши по согласованным условиям.

#### Scenario: Приостановка автосвича при движении мыши

- **WHEN** движение удовлетворяет условию приостановки
- **THEN** новое автоматическое переключение в период приостановки не выполняется
