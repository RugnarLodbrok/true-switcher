# Proposal

## Why

Статистика объединяет pattern switch и словарный auto-switch под одним `mode`, поэтому новые события нельзя анализировать раздельно.

## What Changes

- Для новых записей `switches` использовать `mode=0` для ручного свича, `mode=1` для pattern switch и `mode=2` для словарного auto-switch.
- **BREAKING**: значение `mode=1` для новых записей обозначает только pattern switch. Старые записи остаются без изменений и могут относиться к любому из двух автоматических режимов.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `statistics`: различать источники автоматических свичей в новых записях.

## Impact

Выбор автоматического правила, передача режима коррекции, запись SQLite, тесты и документация статистики. Потребители истории должны учитывать неоднозначность старого `mode=1`.
