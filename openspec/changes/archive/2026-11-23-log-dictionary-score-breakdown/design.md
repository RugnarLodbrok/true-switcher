# Вывод составляющих дельта-скора

## Context

`DictionaryAutoSwitch::comparison` уже вычисляет оба базовых скора и разность счётчиков. Сейчас он возвращает целевой словарь и итоговый дельта-скор, который используют и выбор цели, и логирование.

## Goals / Non-Goals

Взять составляющие из того же сравнения, которое вычисляет итог для проверки порога. Форматирование применяется только при записи в лог.

## Decisions

- Использовать итог словарного сравнения для проверки порога. При формировании сообщения брать из сравнения базовые скоры, а поправку форматировать по разности исходных счётчиков.
- Базовые скоры неположительны, поэтому `альтернативный - текущий` равно `|текущий| - |альтернативный|`. В логе выводить разность модулей.
- Проверять `log_enabled!(Debug)` до вычисления сравнения для лога. Сохранить существующие условия вызова из обработки ввода.
- Если базовых скоров нет в обеих раскладках, вывести пояснение к специальному итогу `+0.00`.

### Примеры формата

```text
DEBUG dict switch score:  +2.25 =  5.75 -  3.50
DEBUG dict switch score:  +3.25 =  5.75 -  3.50 +  1
DEBUG dict switch score:  -4.75 =  8.75 - 12.50 -  1
```

### Пограничные случаи

Нулевой базовый скор и поправка, которая расширяет своё поле и поле дельта-скора.

```text
DEBUG dict switch score:  -5.75 =  0.00 -  5.75
DEBUG dict switch score: +100.00 =  5.75 -  5.75 + 100
```

Базовый скор отсутствует в текущей, альтернативной или обеих раскладках. Последняя строка показывает случай, когда само сравнение недоступно.

```text
DEBUG dict switch score:   +inf =   inf -  3.50
DEBUG dict switch score:   -inf =  5.75 -   inf
DEBUG dict switch score:  +0.00 (both layout scores missing)
DEBUG dict switch score: unavailable
```

## Risks / Trade-offs

Скоры округляются для вывода по отдельности, поэтому равенство по отображаемым числам может расходиться с итогом на последнем знаке.
