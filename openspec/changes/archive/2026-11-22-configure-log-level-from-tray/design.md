# Применение уровня логирования

## Контекст

`main` настраивает `env_logger` на `Trace` и задаёт действующий для процесса порог через `log::set_max_level`. `RuntimeMenu` хранит под mutex значения настроек, которые показывает меню и использует `Save to config`.

## Решения

- Инициализировать уровень в `RuntimeMenu` из `Configuration::log_level`. При выборе уровня обновить значение и вызвать `log::set_max_level` под тем же mutex, который сериализует сохранение. Порог действует на весь процесс и может меняться прямо из обработчика трея без ожидания очереди ввода.
- Экспортировать `Log level` как вложенный узел DBusMenu с группой radio-пунктов. Отдавать их при запросе корня с достаточной глубиной и при запросе самого подменю. При смене уровня публиковать изменение отметок прежнего и нового пунктов.
- Передавать текущее значение в `ConfigurationFile::save` вместе с остальными настройками. Записывать TOML-строку из того же набора имён, который принимает парсер. При замене значения перенести оформление из загруженного документа через `toml_edit::Value::decor`.
