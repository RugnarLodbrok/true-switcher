## ADDED Requirements

### Requirement: Поправка к словарному дельта-скору по сохранённым примерам

При наличии базовых скоров в обеих раскладках True Switcher SHALL прибавить к их разности счётчик альтернативной раскладки и вычесть счётчик текущей. При наборе счётчик равен сумме по сохранённым словам с введённым префиксом в соответствующей раскладке. На первом пробеле учитывается только точное слово. Отсутствие совпадения среди сохранённых примеров даёт счётчик `0`.

#### Scenario: Предпочтение получившейся раскладки

- **WHEN** сохранённый пример в альтернативной раскладке совпадает с префиксом при наборе
- **THEN** его счётчик повышает дельта-скор переключения в эту раскладку

#### Scenario: Сохранение текущей раскладки

- **WHEN** сохранённый пример в текущей раскладке совпадает с префиксом при наборе
- **THEN** его счётчик понижает дельта-скор переключения из этой раскладки

#### Scenario: Переход от префикса к точному слову

- **WHEN** `кот` сохранён дважды, `котик` трижды в той же раскладке и пользователь вводит `кот` с пробелом
- **THEN** счётчик этой раскладки равен пяти на префиксе `кот` и двум на первом пробеле

### Requirement: Базовый скор при отсутствии словарного совпадения

При положительном счётчике сохранённых примеров и нулевой словарной частоте True Switcher SHALL брать базовый скор `−log2(total)` для этой раскладки. `total` — сумма частот основного словаря после фильтрации. Если базовый скор есть только в альтернативной раскладке, дельта-скор SHALL быть `+∞`, если только в текущей — `−∞`. Если базового скора нет в обеих раскладках, дельта-скор SHALL быть `0`.

#### Scenario: Сохранённый пример вне основного словаря

- **WHEN** для одной раскладки есть совпадение только среди сохранённых примеров, а для другой есть положительная словарная частота
- **THEN** для первой раскладки используется `−log2(total)`, и дельта-скор с поправкой конечен

#### Scenario: Базовый скор есть только в одной раскладке

- **WHEN** положительная частота или положительный счётчик есть только в одной раскладке
- **THEN** дельта-скор равен `+∞` для совпадения в альтернативной раскладке или `−∞` для совпадения в текущей

#### Scenario: Совпадений нет в обеих раскладках

- **WHEN** в обеих раскладках словарная частота и счётчик сохранённых примеров равны нулю
- **THEN** дельта-скор равен `0`, словарный запрос не создаётся

### Requirement: Приоритет regex при обучении

True Switcher SHALL учитывать сохранённые примеры при выборе цели только после проверки включённых regex.

#### Scenario: Совпадение с regex

- **WHEN** включённый regex задаёт применимую цель и сохранённый пример влияет на словарный дельта-скор
- **THEN** цель определяется по regex

## MODIFIED Requirements

### Requirement: Выбор по префиксу

При включённом `auto_switch` True Switcher SHALL сравнивать дельта-скор с порогом целевого словаря. Базовый скор равен `log2(P)`, где `P` — нормированная словарная частота префикса при наборе и точного слова на первом пробеле. На обоих этапах словарный свич SHALL пропускаться, если все нажатия токена сделаны одной клавишей и с одинаковым Shift, а это сочетание даёт знак Unicode Punctuation или бэктик в текущей раскладке. Завершающий пробел не входит в токен.

#### Scenario: Выбор по префиксу

- **WHEN** дельта-скор равен порогу
- **THEN** словарный запрос не создаётся

#### Scenario: Одиночный знак и повторения сохраняются

- **WHEN** пользователь в US-раскладке вводит один или три бэктика, `""` либо `''`, а словарная оценка в пользу RU прошла бы порог
- **THEN** словарный запрос не создаётся при наборе и на первом завершающем пробеле

#### Scenario: Разные знаки оцениваются по словарю

- **WHEN** пользователь в US-раскладке вводит бэктик и `;`, а обычная словарная оценка для `ёж` проходит порог
- **THEN** создаётся словарный запрос в RU-раскладку

#### Scenario: Смена состояния Shift

- **WHEN** пользователь в US-раскладке вводит `'"` одной клавишей, сначала без Shift, затем с Shift
- **THEN** к токену применяется обычная словарная оценка

#### Scenario: Пунктуация в альтернативной раскладке оценивается по словарю

- **WHEN** пользователь в RU-раскладке набирает `жжение`, а префиксу `жж` соответствует `;;` в US-раскладке
- **THEN** вариант `;;` получает обычную словарную частоту без бонуса за пунктуацию

#### Scenario: Повторяющаяся пунктуация при обучении

- **WHEN** поправка поднимает словарный дельта-скор выше порога для токена, который подпадает под защиту повторяющейся пунктуации
- **THEN** словарный автосвич пропускается
