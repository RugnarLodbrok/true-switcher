# Дизайн обучения через Shift

## Context

`Input` отслеживает удерживаемые клавиши и формирует `SwitchRequest`. `Switcher` выполняет коррекцию и получает результат перепечатывания. Основной словарный trie хранит состояние префикса для обеих раскладок и использует пробел как маркер конца слова.

## Goals / Non-Goals

Один жест пополняет словарную статистику пользователя. Семантика обычной ручной коррекции и порядок проверки regex сохраняются.

## Decisions

1. Считать Shift в момент нажатия `switch_key` и передать признак сохранения в запросе коррекции. После успешного перепечатывания взять текст именно того слова, которое коррекция обработала, в фактически выбранной раскладке. Прибавить единицу к записи `(раскладка, текст)` в `learned-rules.toml`. Для обоих сценариев применяется одна операция.
2. В `learned-rules.toml` хранить по одной таблице на раскладку с теми же идентификаторами, что в `dict.target`. Ключ — текст без завершающих пробелов, значение — положительное целое число.

   ```toml
   [ru]
   "жжение" = 3

   [us]
   "don't" = 1
   ```

   Для каждой словарной раскладки использовать отдельный trie сохранённых примеров (`trie2`). В `trie2` слово заканчивается одним пробелом. Узлы префикса отдают сумму сырых счётчиков, узел после пробела отдаёт счётчик точного слова. Обновлять `trie2` после сохранения.
3. Основной trie (`trie1`) при загрузке суммирует частоты префиксов и затем предвычисляет скор `log2(frequency / total)` для узлов с положительной частотой. Для каждого словаря также предвычислить `−log2(total)`, где `total` — сумма частот после `dict_skip_pattern`.
4. По одной и той же последовательности нажатий продвигать префиксы `trie1` и `trie2` в обеих раскладках. На первом пробеле искать точное слово. Для каждой раскладки брать базовый скор из `trie1`, если частота положительная. Если положительной частоты нет, а счётчик `trie2` положительный, использовать `−log2(total)`. Сохранение примера обновляет только `trie2` и `learned-rules.toml`.
5. Если базовые скоры есть в обеих раскладках, вычислить дельта-скор по формуле.

   ```text
   delta_score = log_p_alt - log_p_current + learned_alt - learned_current
   ```

   Если базовый скор есть только в альтернативной раскладке, дельта-скор равен `+∞`, если только в текущей — `−∞`. Если обе раскладки остались без базового скора, дельта-скор равен `0`. Ошибка преобразования нажатий в текст прерывает словарную оценку. Полученный дельта-скор сравнивается с порогом альтернативного словаря.

## Risks / Trade-offs

Сохранённый пример влияет и на ввод других слов с тем же префиксом. Например, счётчик `жжение` влияет на решение при вводе `жж` и перестаёт учитываться на `ё` в `жжёт`.
