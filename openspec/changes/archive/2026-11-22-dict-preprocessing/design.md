# Dict preprocessing

## Context

`DictionaryAutoSwitch::load` загружает оба словаря при подготовке конфигурации. `DictionaryTrie::read` разбирает строки, пропускает слова с заглавными буквами и накапливает частоты принятых записей.

## Goals

Встроить настраиваемый фильтр в существующую загрузку словарей при запуске и `Reload`.

## Decisions

- Читать `dict_skip_pattern` как строку со значением по умолчанию `''` в `Configuration`. В `DictionaryAutoSwitch::load` один раз подготовить из непустого значения `regex::Regex` для совпадения со словом целиком и передавать один экземпляр в `DictionaryTrie::read` для обоих словарей. Ошибку компиляции вернуть через существующий путь ошибки конфигурации.
- Удалить проверку регистра из `DictionaryTrie::read`. Проверять regex на исходном поле слова после `parse_record`. Подсчитывать частоты, проверять дубликаты и строить trie по оставшимся записям.

## Risks / Trade-offs

Широкий regex может оставить словарь без положительной суммарной частоты. Существующая проверка суммы вернёт ошибку с путём к файлу.

`DictionaryTrie::advance` приводит ввод к нижнему регистру. Запись `Apple` увеличит общую частоту словаря, а при вводе `Apple` поиск будет идти по префиксу `apple`.
