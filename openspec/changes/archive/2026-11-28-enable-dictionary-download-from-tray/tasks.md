# Задачи

## 1. Запуск без словарной пары

- [x] 1.1 Отбирать `[[dict]]` по текущим `target` KDE до подсчёта и проверки файлов. Различить отсутствие пары и ошибки актуальных словарей. Проверить тестами пустой и неполный набор, отсутствующий файл актуального словаря при обоих значениях `auto_switch`, некорректные данные, пропуск неактуальной записи с отсутствующим файлом, возврат раскладки, лимит по актуальным записям и требование актуальной пары для `score`.
- [x] 1.2 Передавать эффективное значение `auto_switch` в обычный сеанс и отправлять предупреждение в лог и desktop notification при запрошенном автосвиче без пары. Покрыть тестами обычный запуск, сохранение значения на диске и единственное уведомление.

## 2. Настройки и меню трея

- [x] 2.1 Сохранять только изменённое поле при переключении или смене уровня логирования. Обновлять snapshot после успешной записи. Убрать `Save to config` и добавить `separator` после `Log level`. Обновить тесты меню и TOML на немедленное сохранение, `Reload`, сохранение ручных правок, восстановление удалённого файла из последнего записанного snapshot и сохранение прежнего snapshot при ошибке записи.
- [x] 2.2 Добавить подменю `Auto-switch → Download dictionaries` при отсутствии пары и обычную галку при наличии пары. В подменю вывести источники в порядке TOML с действиями `Open in browser` и `Download`, затем разделитель и `Open dict-sources.toml`. Покрыть тестами структуру dbusmenu, порядок источников, привязку действий к выбранному источнику, открытие активного файла и ограничения KDE.
- [x] 2.3 Читать `dict-sources.toml` рядом с активным `config.toml` при старте, а при открытии `Download dictionaries` проверять `mtime` и наличие файла. Проверить тестами отсутствие повторного чтения при неизменном файле, обновление списка при изменении или появлении файла, сообщение об отсутствующем файле после удаления, сообщение об ошибке чтения или разбора с `Open dict-sources.toml` и обновление после исправления.

## 3. Скачивание и подключение

- [x] 3.1 Разрешать скачивание при ровно двух уникальных `target`. Получать в фоне файлы по `url_template` выбранного источника для каждого уникального `target`. Проверить тестами отказ до сетевых запросов, записи конфига и `Reload` при числе уникальных `target`, отличном от двух, и выбор первого варианта в порядке KDE, точный вариант и переход к базовому имени, отсутствие мапинга у первого варианта, отдельную диагностику 404, сохранение `[[dict]]` в обоих случаях, единственную одновременную загрузку и сетевые ошибки.
- [x] 3.2 Проверить формат каждого файла, установить файлы с запретом перезаписи в `dicts/<directory>/<target>/`, обновить только `file` существующих `[[dict]]` по совпадающему `target` или добавить запись, сохранить `auto_switch = false` и запросить `Reload`. Использовать общую операцию сохранения, которая применяет правку к актуальному TOML и обновляет snapshot после успешной записи. Покрыть тестами одноимённые файлы разных источников, разные коды раскладки и словаря, сохранение других полей и неактуальных записей, подключение пары со снятой галкой и её неактивность при более чем двух раскладках KDE с двумя уникальными `target`, переиспользование файла, появление файла во время скачивания и сохранение ручных правок и настроек трея, внесённых во время скачивания.
- [x] 3.3 Показывать ход операции и итог в одном desktop notification. Проверить тестами повторное использование ID, отображение хода с известным и неизвестным размером и итог до `Reload`.

## 4. Установка

- [x] 4.1 При установке создавать `dict-sources.toml` из `installer/dict-sources.example.toml` рядом с пользовательским конфигом, если файла ещё нет. Покрыть тестами чистую установку, создание файла источников при существующем `config.toml` и сохранение существующего `dict-sources.toml`.
