# Загрузка словарей из трея

## Context

Сейчас служба загружает словари до обычного трея. Трей получает наличие пары при запуске. `Reload` уже перезапускает службу через systemd. Текущая операция `Save to config` атомарно записывает копию TOML, прочитанную при запуске, со всеми значениями трея.

## Goals / Non-Goals

Переиспользовать обычный запуск, desktop notifications и `Reload`. Сохранить текущее поведение ручной и regex-коррекции при отсутствии настроенной пары.

## Decisions

### Различать отсутствие словарей и ошибки

Перед подсчётом и проверкой словарей отобрать записи `[[dict]]`, чьи `target` соответствуют текущим базовым именам раскладок KDE. Хранить остальные записи в TOML и пропускать их вместе с файлами. Если раскладка с этим `target` снова появится, запись снова участвует в загрузке.

Вернуть из загрузки для службы явный результат об отсутствии пары, когда после отбора осталось ноль записей или одна корректная запись с доступным файлом. Ошибка открытия актуального словаря, включая `NotFound`, ведёт в аварийный трей. Проверять лимит числа раскладок для включённого автосвича, когда пара доступна.

Передать эффективное `auto_switch = false` в обработчик ввода и обычный трей. Запрос `auto_switch = true` из конфига в этом случае создаёт предупреждение и одно desktop notification на запуск или `Reload`. Сбой доставки уведомления обрабатывается в обычном режиме. Команда `score` требует пару для расчёта после того же отбора по `target`.

### Сохранять изменение отдельного поля

При загрузке конфига сохранить разобранный TOML как snapshot. Для автосохранения настроек трея и подключения словарей использовать одну операцию сохранения. Сериализовать чтение, правку, запись и обновление snapshot между этими операциями. При каждом сохранении прочитать актуальный TOML, чтобы учесть ручные правки. Если файл удалён, взять snapshot. Применить правку через `toml_edit` с сохранением оформления и атомарно заменить файл. Только после успешной замены обновить snapshot записанным документом.

Изменённую настройку трея применять в текущем сеансе сразу. Запись логировать с прежним уровнем, если пользователь выбрал `off`, чтобы ошибка сохранения не исчезла из-за самой правки.

Изменение другого переключателя сохраняет запрошенный пользователем `auto_switch`, даже когда эффективное значение равно `false`. Скачивание словарей из трея явно сохраняет `auto_switch = false` перед `Reload`.

### Использовать свойства dbusmenu

При отсутствии пары предоставить для `Auto-switch` свойство `children-display = "submenu"` и дочерний пункт `Download dictionaries`. При наличии пары предоставлять свойства галки. Позицию `Save to config` в корне меню занять пунктом с `type = "separator"` сразу после `Log level`. После `Reload` меню строится заново из результата загрузки.

Обычное меню с загруженной парой, сразу после успешного скачивания и `Reload`:

```text
☐ Auto-switch
☑ Pattern switch
☑ Manual switch sound
☐ Auto-switch sound
Log level ▸
  ○ off
  ○ error
  ○ warn
  ● info
  ○ debug
  ○ trace
────────────────────
Reload
Quit
```

Галка `Auto-switch` после скачивания снята. Остальные отметки приведены для примера. При наличии пары, выключенном автосвиче и более чем двух раскладках KDE вместо первой строки показывать неактивную галку `Auto-switch (requires at most two KDE layouts)`. Если автосвич уже включён, галка остаётся доступна для выключения.

Аварийный трей при ошибке конфигурации, например при отсутствующем файле актуального словаря, использует существующее меню:

```text
Reload
Quit
```

Подменю `Download dictionaries` показывает `[[source]]` по `name` в порядке файла. У каждого источника `Open in browser` открывает его `link`, а `Download` запускает скачивание из него. После источников идёт `separator`, затем `Open dict-sources.toml`, который открывает активный файл источников в приложении по умолчанию.

Ветка `Auto-switch` без пары при двух уникальных `target` и доступном списке источников:

```text
Auto-switch ▸
  Download dictionaries ▸
    FrequencyWords 2016 by hermitdave on github ▸
      Open in browser
      Download
    FrequencyWords 2018 by hermitdave on github ▸
      Open in browser
      Download
    ────────────────────
    Open dict-sources.toml
```

Без пары при числе уникальных `target`, отличном от двух, показывать неактивную строку ошибки вместо списка источников. Если файл источников отсутствует, опустить разделитель и `Open dict-sources.toml`.

Меньше двух уникальных `target`, в том числе несколько вариантов одной базовой раскладки:

```text
Auto-switch ▸
  Download dictionaries ▸
    Error: Dictionary download requires two distinct layouts
    ────────────────────
    Open dict-sources.toml
```

Три и более уникальных `target`:

```text
Auto-switch ▸
  Download dictionaries ▸
    Error: Dictionary download supports at most two distinct layouts
    ────────────────────
    Open dict-sources.toml
```

### Получать ключи из настроек источника

При установке копировать `installer/dict-sources.example.toml` в `dict-sources.toml` рядом с `config.toml`. Создавать файл только при его отсутствии, независимо от того, существует ли `config.toml`. Переиспользовать подход инсталлера с эксклюзивным созданием файла.

Читать `dict-sources.toml` рядом с активным `config.toml` при старте и хранить результат чтения вместе с состоянием файла. При открытии `Download dictionaries` проверять `mtime` и перечитывать файл после изменения или появления. При удалении заменять список источников сообщением `error: <путь>/dict-sources.toml is missing`. При ошибке чтения или разбора показывать путь и причину, сохраняя `Open dict-sources.toml` для существующего файла.

Файл источников отсутствует:

```text
Auto-switch ▸
  Download dictionaries ▸
    error: <путь>/dict-sources.toml is missing
```

Файл источников существует, но чтение или разбор завершились ошибкой:

```text
Auto-switch ▸
  Download dictionaries ▸
    error: <путь>/dict-sources.toml: <причина>
    ────────────────────
    Open dict-sources.toml
```

Каждая запись `[[source]]` содержит `name` для отображения, `directory` для хранения, `link` для страницы источника, `url_template` с `{key}` и собственную таблицу `[source.layout_keys]`. Это позволяет одному выпуску использовать `cn = "zh"`, а другому — `cn = "zh_cn"`. Пример использует URL на ветку форка. Для загруженных и существующих файлов применяется штатная проверка формата.

До сетевых запросов обойти раскладки в порядке KDE и оставить первую запись для каждого базового имени, как при существующем поиске раскладки по `target`. Остальные варианты с этим именем пропустить до поиска ключей. Для каждого оставшегося варианта сначала искать точную запись, например `us(rus)`, затем базовое имя `us`. Значение из таблицы используется для URL, идентификатор базовой раскладки — для `[[dict]].target`. Если у выбранного первого варианта нет ни точного, ни базового мапинга, операция завершается до скачивания. HTTP 404 завершает её с отдельной диагностикой. В обоих случаях уведомление и лог содержат раскладку и путь к активному `dict-sources.toml`. Для 404 также указать ключ.

При пополнении таблиц использовать `languageList` из XKB как подсказку, сверять ключи со списком каталогов соответствующего выпуска и вручную выбирать ключи для неоднозначных и региональных раскладок.

### Устанавливать словари в фоне

Перед запуском скачивания проверить число уникальных `target` в актуальных раскладках KDE. Разрешить скачивание при двух уникальных `target`. В остальных случаях показать соответствующую ошибку в `Download dictionaries` и завершить действие до сетевых запросов, записи конфига и `Reload`.

При двух уникальных `target` и более чем двух раскладках KDE скачать и подключить пару. После `Reload` показать снятую неактивную галку `Auto-switch (requires at most two KDE layouts)`.

Рабочая задача вне обработчиков D-Bus и ввода определяет целевой файл для каждого выбранного `target`. Перед изменением конфига проверить, что набор и порядок раскладок KDE сохранились.

Строить целевой путь как `dicts/<directory>/<target>/<имя файла>` относительно каталога конфига. Брать имя файла из последнего сегмента пути сформированного URL. Для `us = "en"` из выпуска 2016 получается `dicts/frequency-words-2016/us/en_full.txt`. По этому пути использовать существующий файл. При его отсутствии скачать во временный файл и разместить атомарно с запретом перезаписи. Если другой процесс успел создать целевой файл, проверить и использовать его.

Перед записью конфига проверить содержимое каждого файла отдельно. Затем в общей операции сохранения обновить относительный путь в `file` существующей записи `[[dict]]` по `target` либо добавить запись с порогом из примера конфигурации. Сохранить остальные поля словарей и записи для `target`, которых нет в KDE. Записать `auto_switch = false`. После успешной записи и обновления snapshot вызвать существующий `Reload`. При ошибке до записи конфига освободить временные файлы и сохранить возможность повторить загрузку.

### Обновлять одно уведомление

Использовать существующий интерфейс `org.freedesktop.Notifications`. Сохранить ID первого `Notify` и передавать его как `replaces_id` с ограничением частоты обновлений. Во время скачивания показывать процент по байтам при известном общем размере или объём скачанного. Затем показать проверку словарей и итог. При успехе отправить итог перед `Reload`.

## Risks / Trade-offs

- `Reload` в конце операции кратко прерывает работу службы. Существующий lifecycle выполняет перезапуск и загружает словари обычным путём.
- При трёх и более актуальных записях `[[dict]]` загрузчик отклоняет конфиг даже при `auto_switch = false`. Проверка числа уникальных `target` до скачивания предотвращает создание такого конфига через трей. Поддержка этих конфигов отложена до отдельного изменения автосвича.
- Сетевой сбой или неполный ответ оставляет автосвич выключенным и даёт пользователю повторить операцию. Файлы проходят проверку формата до подключения.
