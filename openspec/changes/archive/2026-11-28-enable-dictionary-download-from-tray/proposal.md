# Загрузка словарей из трея

## Why

Сейчас `auto_switch = true` без словарей переводит приложение в аварийный режим. 

Изменения конфига через трея вступают в силу сразу, но сохраняются отдельной командой.

## What Changes

- При загрузке словарей учитывать только `[[dict]]` для текущих раскладок KDE. Без полной пары запустить приложение с выключенным словарным автосвичем. Если конфиг запрашивал `auto_switch = true`, записать предупреждение в лог и показать уведомление. Отсутствующий файл актуального словаря считать ошибкой конфигурации.
- Без загруженной пары показывать подменю `Auto-switch → Download dictionaries` со списком источников из `dict-sources.toml` или ошибкой чтения файла. Прочитать файл при старте и подхватывать изменения при открытии подменю. У каждого источника есть действия `Open in browser` и `Download`. После списка показать разделитель и `Open dict-sources.toml`.
- Разрешать скачивание словарей из выбранного источника при ровно двух уникальных `target`. При совпадении базового имени брать первый вариант в порядке KDE. Хранить файлы в отдельных каталогах по источникам и раскладкам, переиспользовать существующие файлы. После проверки формата обновлять `file` по `target` или добавлять `[[dict]]`, сохраняя записи для остальных `target`. Показывать прогресс в одном уведомлении и запрашивать `Reload` после сохранения.
- При установке копировать `installer/dict-sources.example.toml` в `dict-sources.toml` рядом с `config.toml`, если файла ещё нет.
- Сохранять каждую изменённую настройку трея сразу. При сохранении настройки или подключении словарей применять правку к актуальному TOML и обновлять snapshot после успешной записи. Убрать `Save to config` и поставить горизонтальный разделитель после подменю `Log level`.

### New Capabilities

### Modified Capabilities

- `auto-switch` — запуск без доступной пары словарей.
- `installation` — создание стартового файла источников.
- `session-lifecycle` — меню, сохранение настроек, уведомления и загрузка по запросу.

## Impact

Инсталлер, подготовка конфигурации, загрузчик словарей, сохранение TOML, обычный трей, dbusmenu и desktop notifications.
