# Словарный автосвич

## MODIFIED Requirements

### Requirement: Конфигурация словарей

При запуске и `Reload` True Switcher SHALL учитывать только `[[dict]]` с `target` из текущих раскладок KDE. Актуальные записи SHALL иметь разные `target`, относительные пути и конечные положительные пороги. Без полной пары приложение SHALL продолжать запуск с эффективным `auto_switch = false`. Ошибки настроек или файлов считаются ошибками конфигурации для актуальных записей.

#### Scenario: Ручная коррекция без словарей

- **WHEN** `auto_switch = false` и `dict` отсутствует или пуст
- **THEN** True Switcher запускается без файлов словарей, поддерживает ручную коррекцию и сохраняет примеры через `Shift + switch_key`
- **AND** включённые regex-правила применяются

#### Scenario: Включённый автосвич без словарей

- **WHEN** при запуске или `Reload` задано `auto_switch = true`, а среди актуальных `[[dict]]` нет записей или есть одна корректная запись с доступным файлом
- **THEN** True Switcher работает в обычном режиме с выключенным словарным автосвичем
- **AND** приложение пишет предупреждение с причиной и один раз показывает уведомление о выключении автосвича
- **AND** загрузка сама по себе сохраняет запрошенное значение `auto_switch` в файле конфигурации

#### Scenario: Конфигурация словарей

- **WHEN** задана одна актуальная и корректная запись `[[dict]]` с доступным файлом при выключенном `auto_switch`
- **THEN** True Switcher запускается без загруженной пары

#### Scenario: Неактуальный target

- **WHEN** в `config.toml` есть `[[dict]]` с `target`, которого нет в текущих раскладках KDE
- **THEN** True Switcher сохраняет запись в конфиге, пропускает её при подсчёте словарей и не открывает её файл
- **AND** при следующем запуске или `Reload` запись снова учитывается, если раскладка с этим `target` вернулась

#### Scenario: Некорректный файл актуального словаря

- **WHEN** файл актуального `[[dict]]` отсутствует, содержит некорректные данные или чтение завершается ошибкой доступа
- **THEN** True Switcher сообщает об ошибке конфигурации
- **AND** проверка выполняется при любом значении `auto_switch`, в том числе при одной записи `dict`

#### Scenario: Словари настроены при выключенном автосвиче

- **WHEN** `auto_switch = false` и среди `[[dict]]` есть ровно две актуальные корректные записи
- **THEN** True Switcher загружает оба словаря при запуске

#### Scenario: Больше двух актуальных записей словарей

- **WHEN** при запуске или `Reload` в конфиге больше двух актуальных записей `[[dict]]`
- **THEN** приложение показывает аварийный трей с ошибкой `Exactly two dictionaries must be configured` при любом значении `auto_switch`
