# Design

## Context

В `Input::process_text_event` проверка паузы стоит до `update_auto_switch`. Эта функция выбирает автозапрос и записывает `is_ambiguous` в историю. `correction_word_count` расширяет диапазон по сохранённым пометкам.

## Decisions

- Во время паузы передавать в `update_auto_switch` только первый завершающий пробел при включённом `auto_switch`. На нём использовать существующий `DictionaryDecision` и текущий порядок проверок `switch_rules`, чтобы критерии пометки совпадали с обычным вводом.
- Учитывать паузу при обновлении `PendingSwitch`. Применимое правило Pattern Switch по-прежнему исключает словарную пометку, а результат `Switch` во время паузы пропускается. Только результат `Ambiguous`, прошедший защитные проверки, обновляет историю.

## Risks / Trade-offs

Во время паузы оценка понадобится на первом пробеле. Обработку префиксов для автозапросов по-прежнему пропускать, чтобы набор во время движения мыши обходился без дополнительной оценки на каждом символе.
