# Design

## Context

`Input::process_text_event` проверяет допустимость автоматической оценки. `Input::update_auto_switch` выбирает результат и применяет его.

## Goals / Non-Goals

Описать результат оценки независимо от состояния очереди запросов. Время оценки, история и жизненный цикл запроса принадлежат `Input`.

## Decisions

`AutoSwitch` получает слово, текущую раскладку, runtime settings и признак первого пробела. Он возвращает `Keep`, `Ambiguous` или `Switch` с целью и видом правила. Сначала проверяется pattern для целевой раскладки, затем словарь. Pattern текущей раскладки может заблокировать словарный `Switch` и `Ambiguous`. Словарные guards остаются в dictionary decision.

`Input` сохраняет существующие guards для оценки. Во время mouse pause он оценивает только первый пробел при включённом словарном автосвиче, сохраняет полученный `Ambiguous` и пропускает постановку автозапроса. Вне паузы `Input` применяет результат через текущий `PendingSwitch::update_auto`. Так правило паузы сосредоточено в обработчике ввода.

## Risks / Trade-offs

Проверить приоритет pattern на первом пробеле во время паузы и последующую коррекцию цепочки. Сохранить очистку устаревшей цели, защиту ручного запроса и реакцию на неизвестную раскладку.
