# Штраф за разбиение токена

## Why

Сейчас разбиение по пунктуации может завышать скор коротких последовательностей. При наборе `общий` в US разбиение `j,ob` на `j` и `ob` снижает `dscore` в пользу RU до `+1.10`.

```text
Text (us)  Text (ru)  Score (us)  Score (ru)  Delta  Above threshold
j          о               -6.81       -4.20   2.62  no
j,         об             -15.77       -7.30   8.46  no
j,o        общ            -15.77      -11.31   4.46  no
j,ob       общи           -15.77      -14.67   1.10  no
j,obq      общий          -27.13      -16.16  10.97  no
j,obq␣     общий␣         -27.13      -16.16  10.97  no
```

## What Changes

- Добавить `split_score_penalty`. Значение по умолчанию `6`
- В каждой раскладке вычитать штраф один раз из минимума итоговых скоров частей, затем сравнивать результат со скорами полного и обрезанного ключей.

Загрузка `config.toml`, пример в `installer/config.example.toml` и общий словарный скоринг для автосвича, debug-лога и команды `score`.
