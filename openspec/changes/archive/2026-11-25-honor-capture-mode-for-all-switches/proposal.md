# Единый режим захвата для всех свичей

## Why

Словарная коррекция нескольких слов включает `grab` даже при `IS_CAPTURE_ENABLED = false`. Из-за этого многословный свич ждёт физического отпускания обычных клавиш при выключенном захвате.

## What Changes

- Выбирать режим захвата для любого свича по `IS_CAPTURE_ENABLED` независимо от количества слов и способа запуска.
- При выключенном захвате применять существующий протокол синтетического отпускания клавиш ко всему диапазону коррекции.

## Capabilities

### New Capabilities

### Modified Capabilities

- `layout-correction` определяет выбор режима захвата для ручных, паттерных и словарных свичей.

## Impact

Изменение затрагивает выбор `CorrectionInterceptor` и тесты однословной и многословной коррекции.
