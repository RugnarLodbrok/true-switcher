# Proposal

## Why

Свежая установка создаёт `config.toml` без словарей. Текущая проверка требует два словаря даже при выключенном `auto_switch`, поэтому ручная коррекция сразу после установки недоступна.

## What Changes

- Установщик создаёт `config.toml` из шаблона в `installer/`. В шаблоне указаны значения по умолчанию, пояснения к настройкам и закомментированные примеры словарей `us` и `ru`. [config.example.toml](../../../../installer/config.example.toml)
- При `auto_switch = false` приложение запускается без `[[dict]]`. Пользователь может сразу исправлять слова вручную и настраивать regex-правила независимо от словарей.
- Для включения словарного автосвича нужны два загруженных словаря. Трей показывает причину, если включение недоступно.

## Capabilities

### New Capabilities

### Modified Capabilities

- `installation` — стартовый конфиг с документированными настройками.
- `auto-switch` — загрузка конфигурации без словарей при выключенном `auto_switch`.
- `session-lifecycle` — доступность словарного автосвича в трее.

## Impact

Изменение затрагивает шаблон установщика, загрузчик словарей, меню трея и инструкцию первого запуска в README.
