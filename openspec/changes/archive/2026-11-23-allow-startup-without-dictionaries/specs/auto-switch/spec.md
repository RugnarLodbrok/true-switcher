## MODIFIED Requirements

### Requirement: Конфигурация словарей

При `auto_switch = false` True Switcher SHALL допускать отсутствующий или пустой список `dict`. При включённом `auto_switch` или наличии записей `dict` True Switcher SHALL проверять ровно две записи с разными целями, относительными путями и конечными положительными порогами и загружать оба словаря.

#### Scenario: Ручная коррекция без словарей

- **WHEN** `auto_switch = false` и `dict` отсутствует или пуст
- **THEN** True Switcher запускается без файлов словарей, поддерживает ручную коррекцию и сохраняет примеры через `Shift + switch_key`
- **AND** включённые regex-правила применяются

#### Scenario: Включённый автосвич без словарей

- **WHEN** `auto_switch = true` и `dict` отсутствует или пуст
- **THEN** загрузка конфигурации завершается ошибкой с указанием требования к двум словарям

#### Scenario: Конфигурация словарей

- **WHEN** в `dict` явно задана одна запись даже при выключенном `auto_switch`
- **THEN** загрузка конфигурации завершается ошибкой

#### Scenario: Словари настроены при выключенном автосвиче

- **WHEN** `auto_switch = false` и заданы две корректные записи `dict`
- **THEN** True Switcher загружает оба словаря при запуске
