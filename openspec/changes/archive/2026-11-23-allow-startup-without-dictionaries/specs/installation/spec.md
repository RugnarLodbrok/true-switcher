## ADDED Requirements

### Requirement: Стартовый конфиг

Установщик SHALL создавать `config.toml` копированием `installer/config.example.toml`. Шаблон SHALL содержать явные значения по умолчанию для клавиши коррекции, логирования, режимов переключения, звуков и словарных фильтров, пояснения к настройкам, закомментированный пример `[[switch_rules]]` и два закомментированных примера `[[dict]]` для `us` и `ru` с относительными путями и порогами.

#### Scenario: Чистая установка

- **WHEN** пользователь устанавливает True Switcher без существующего `config.toml` и без файлов словарей
- **THEN** новый конфиг содержит `switch_key = "KEY_PAUSE"` и `auto_switch = false`, запускается ручная коррекция
- **AND** комментарии объясняют, куда положить словари и как включить словарный автосвич

#### Scenario: Существующий конфиг

- **WHEN** к началу установки у пользователя есть `config.toml`
- **THEN** установщик сохраняет содержимое файла
