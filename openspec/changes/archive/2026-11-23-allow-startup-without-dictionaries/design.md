# Design

## Context

`AutoSwitchRules::new` загружает словари до запуска обычного трея. При переключении `Auto-switch` трей проверяет число раскладок KDE и применяет новый флаг к уже загруженным данным.

## Goals / Non-Goals

Поддержать запуск без словарей и сохранить мгновенное включение автосвича для загруженной пары. Состав словарей подхватывается при запуске и `Reload`.

## Decisions

- Загрузчик допускает пустой набор при выключенном `auto_switch`. Для непустого набора сохраняются проверка пары и загрузка файлов даже при выключенном автосвиче, чтобы переключатель в трее работал сразу. Явно заданные словарные regex валидируются и для пустого набора.
- Объект словарных правил с пустым набором сохраняет `LearnedRules`. Запись примеров через `Shift + switch_key` использует тот же путь при любом состоянии словарей.
- Передать в обычное меню признак наличия загруженной пары из результата загрузки. При отсутствии пары пункт недоступен и предлагает настроить словари и выбрать `Reload`. При наличии пары применяются существующие проверки KDE. Обработчик пункта проверяет доступность перед изменением флага.
- После предварительных проверок `make install` установщик проверяет, есть ли `~/.config/true-switcher/config.toml`. Если его нет, установщик читает шаблон рядом с `installer.py` и затем создаёт пользовательский файл с тем же содержимым. Ошибка чтения шаблона прерывает установку до создания пользовательского файла. Существующий `config.toml` сохраняется без чтения шаблона. При запуске и `Reload` приложение читает пользовательский `config.toml`. [config.example.toml](../../../../installer/config.example.toml)

## Risks / Trade-offs

- Шаблон содержит явные значения по умолчанию. Тесты сверяют, что эти значения дают ожидаемый режим и что шаблон загружается без словарей.
- Старые конфиги остаются на месте. Конфиг без словарей с выключенным автосвичем становится рабочим при следующем запуске или `Reload`.
