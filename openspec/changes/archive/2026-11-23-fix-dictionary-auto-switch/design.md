# Дизайн фиксов словарного автосвича

## Context

`AutoSwitchRules::target` пропускает правила для текущей раскладки. `Input::update_auto_switch` сначала ищет цель по regex, затем передаёт словарного кандидата в `PendingSwitch::update_auto`. Этот метод отменяет ожидающий автосвич, когда новая оценка возвращает `None`.

`DictionaryAutoSwitch::layout_score` берёт `DictionaryTrie::minimum_score` при нулевой словарной частоте и положительном счётчике сохранённых примеров. `minimum_score` равен `−log2(total)` конкретного словаря.

`DictionaryAutoSwitch::target` блокирует кандидата через `is_repeated_punctuation`, если токен набран одной и той же клавишей с одинаковым Shift и даёт знак пунктуации или бэктик.

## Goals / Non-Goals

Выполнить обратную проверку `switch_rules` в `Input`. В `DictionaryAutoSwitch` проверять защиту пунктуации по тексту токена и задавать одинаковый исходный вес для сохранённых примеров вне основного словаря в обеих раскладках.

## Decisions

1. Вынести преобразование нажатий в текст для regex в общий метод `AutoSwitchRules`. Использовать тот же регистр, то же преобразование раскладки и тот же завершающий пробел для проверки в обоих направлениях.
2. При обратной проверке смотреть только правила с целью в текущей раскладке и завершать поиск на первом совпадении. Это проверка наличия совпадения, поэтому порядок правил влияет только на выбор прямой цели.
3. В `Input::update_auto_switch` проверять обратное совпадение только после получения словарного кандидата и только при включённом `pattern_switch`. При совпадении передавать `None` в `PendingSwitch::update_auto`, чтобы убрать ожидающий запрос через существующий путь обновления.
4. Использовать общую константу `−18` в `DictionaryAutoSwitch::layout_score` вместо `DictionaryTrie::minimum_score`. В комментарии рядом с константой объяснить выбор. На шкале `log2(P)` значение соответствует весу редкого совпадения, примерно одному на 262 тысячи. Фиксированный вес сохраняется при пропорциональном пересчёте частот словаря. К базовым скорам применяется существующая поправка по счётчикам `learned`.
5. Заменить `is_repeated_punctuation` проверкой `dict_block_pattern`. Скомпилировать regex при загрузке конфигурации с совпадением по всему токену, как у `dict_skip_pattern`. В DictionaryAutoSwitch::target, если дельта-скор превышает порог, проверить весь токен в текущей раскладке без завершающего пробела. При совпадении отбросить словарный кандидат. PendingSwitch::update_auto отменяет ожидающий словарный запрос через существующий путь обновления.

## Risks / Trade-offs

Обе блокирующие проверки используют текст в текущей раскладке. Обратная проверка `switch_rules` добавляет завершающий пробел на первом пробеле, а `dict_block_pattern` проверяет сам токен.

Защита по умолчанию охватывает сочетание бэктика с `;` в US-раскладке. Для исправления на `ёж` остаются ручной свич и прямое правило `switch_rules`.
