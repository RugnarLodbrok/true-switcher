# Фиксы словарного автосвича

## Why

Словарь может переключить раскладку для текста, который совпадает с regex для текущей раскладки. Сейчас `AutoSwitchRules` проверяет только правила, направленные в другие раскладки.

Защита пунктуации опирается на повтор одного и того же нажатия. Смешанные последовательности вроде `../` и `!?` могут запустить словарный автосвич.

Базовый скор совпадений только в `learned` зависит от суммы частот словаря. Пропорциональное изменение всех частот меняет этот скор при тех же нормированных словарных частотах.

## What Changes

- При включённом `pattern_switch` совпадение с regex, нацеленным на текущую раскладку, блокирует словарный автосвич.
- Отдельный параметр `dict_block_pattern` задаёт защиту от словарного автосвича. По умолчанию он защищает токены, целиком состоящие из пунктуации и бэктиков.
- Для совпадений только в `learned` используется фиксированный базовый скор `−18` в обеих раскладках.

## Impact

`AutoSwitchRules` получит возможность проверять правила для конкретной раскладки. `Input` будет учитывать результат перед созданием ожидающего словарного запроса. `DictionaryAutoSwitch` будет применять `dict_block_pattern` к словарным кандидатам и использовать фиксированный скор при оценке сохранённых примеров вне основного словаря.
