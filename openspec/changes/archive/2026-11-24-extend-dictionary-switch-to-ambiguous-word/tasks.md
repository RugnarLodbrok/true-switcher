# Задачи

## 1. Диапазон коррекции

- [x] 1.1 Передать диапазон последних слов через `SwitchRequest` в `Switcher` и использовать его для стирания, replay и обновления `History`. Проверить существующими тестами `cargo test`, что ручная коррекция с пустой историей, однословный свич и отмена синтетического ввода работают как прежде.

## 2. Неоднозначность слова

- [x] 2.1 Добавить `ambiguity_score_floor` в конфигурацию с дефолтом `-18` и указать `ambiguity_score_floor = -18` в `installer/config.example.toml`. Проверить загрузку шаблона, конфига без параметра и конфига со своим порогом, а также ошибку для недопустимых значений.
- [x] 2.2 Использовать существующее словарное сравнение для оценки неоднозначности на первом пробеле и хранить пометку в истории. Покрыть тестами нижнюю границу, оба порога дельта-скора, совпадение только в `learned`, приоритет паттерна, словарные блокировки и отзыв пометки при удалении разделителя или сбросе истории.

## 3. Словарная коррекция цепочки

- [x] 3.1 Расширять диапазон словарного запроса на всю непрерывную цепочку пригодных неоднозначных слов перед текущим. Покрыть интеграционными тестами свич на префиксе и первом пробеле, цепочку для `а из коробки`, приоритет паттерна, ручной свич и границы цепочки при слове без пометки или с dead key.
- [x] 3.2 Проверить тестами стирание и replay диапазона с несколькими пробелами, обновление раскладки всех слов в истории и защиту от повторной коррекции после Backspace.

## 4. Статистика

- [x] 4.1 Записывать в `switches.a` и `switches.b` исходный и целевой варианты всего диапазона. Проверить тестами одну запись для коррекции трёх слов, сохранение пробелов, поля `prev` и режима, а также запись при отмене replay. Запустить `cargo test`.
