# Design

## Context

`History::process` добавляет stroke. Затем `Input::process_text_event` находит последний entry, а `DictionaryAutoSwitch::push` продвигает стеки. Backspace удаляет запись и откатывает стеки.

## Goals / Non-Goals

Сделать согласованность записей и prefix stacks частью операции редактирования слова. История отвечает за границы слов, пробелы и Backspace, словари продолжают определять следующий prefix.

## Decisions

При добавлении stroke история получает доступ к вычислению следующего prefix и выполняет обе части обновления через одну операцию над словом. В каждом prefix stack хранится по одному состоянию на stroke. При удалении stroke та же граница API откатывает все стеки. Событие истории сообщает вызывающему коду, что введён символ или первый пробел, чтобы путь оценки использовал результат самой операции редактирования.

Префиксы привязаны к физическим stroke и целевым раскладкам словарей. Обновление layout metadata после коррекции не требует пересчёта prefix stacks.

## Risks / Trade-offs

Проверить удаление пробела и целого слова, возврат к предыдущему слову, откат `ConversionFailed` и ввод без словарей.
