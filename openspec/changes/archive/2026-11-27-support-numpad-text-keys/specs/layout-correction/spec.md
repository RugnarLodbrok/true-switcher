# Spec Delta

## MODIFIED Requirements

### Requirement: Синтетический ввод

True Switcher SHALL воспроизводить физические клавиши через виртуальную клавиатуру после успешной смены раскладки. Для сохранённых текстовых клавиш нумпада, которые печатают символ в исходной и целевой раскладках, True Switcher SHALL учитывать символ при удалении и воспроизводить нажатие в исходном порядке вместе с остальными клавишами.

#### Scenario: Синтетический ввод

- **WHEN** на этапе удаления произошла ошибка или поступила отмена
- **THEN** программа не начинает повторный ввод слова

#### Scenario: Коррекция слова с Numpad Plus

- **WHEN** пользователь вводит `гы+кг` в RU с `+` на клавише Numpad Plus и стандартным `punctuation`, а словарный автосвич выбирает US
- **THEN** True Switcher удаляет все пять символов и вводит `us+ru`, воспроизводя `+` через `KEY_KPPLUS`
