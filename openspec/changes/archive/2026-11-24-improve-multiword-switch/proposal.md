# Proposal

## Why

Нижняя граница для каждого словарного скора исключает слова, даже если их дельта-скор укладывается в диапазон неоднозначности. При свиче цепочки статистика сейчас может записать в `prev` слово из самого диапазона коррекции.

## What Changes

- Убрать сравнение отдельных словарных скоров с `ambiguity_score_floor`.
- Для пометки `ambiguous` требовать базовый скор в обеих раскладках. Базовый скор может быть получен из словаря или `learned`.
- **BREAKING**. Заданный `ambiguity_score_floor` становится нижней границей дельта-скора. При отсутствии ключа применяется `-threshold` текущей раскладки.
- При свиче цепочки в `switches.prev` записывать слово непосредственно перед диапазоном коррекции или пустую строку, если такого слова нет в истории.

## Capabilities

### New Capabilities

### Modified Capabilities

- `auto-switch` определяет пометку на первом пробеле по дельта-скору и поддерживает необязательную настройку нижней границы.
- `statistics` сохраняет в `prev` контекст перед фактическим диапазоном коррекции.

## Impact

Изменение затрагивает загрузку `config.toml`, шаблон `installer/config.example.toml`, словарное решение о неоднозначности и формирование контекста для новой записи свича. В существующих конфигурациях явное `ambiguity_score_floor = -18` будет означать нижнюю границу дельта-скора `-18`. Чтобы использовать порог текущей раскладки, нужно убрать ключ из конфига.
