# Spec Delta

## MODIFIED Requirements

### Requirement: Запись свича

True Switcher SHALL сохранять время события, режим и оба варианта диапазона коррекции в `switches.a` (исходный текст) и `switches.b` (целевая раскладка). Оба поля SHALL сохранять порядок слов и пробелы между ними. В `switches.prev` SHALL сохраняться слово непосредственно перед началом диапазона в истории или пустая строка, если такого слова нет. В новых записях `switches` режим SHALL быть `0` для ручного свича, `1` для pattern switch и `2` для словарного auto-switch.

#### Scenario: Запись свича

- **WHEN** раскладка успешно сменилась, но повторный ввод был отменён
- **THEN** запись о переключении сохраняется

#### Scenario: Источник автоматического свича

- **WHEN** свич вызван совпавшим pattern, в том числе при одновременном совпадении словарного правила
- **THEN** новая запись получает `mode=1`

#### Scenario: Словарный auto-switch

- **WHEN** свич вызван словарной эвристикой
- **THEN** новая запись получает `mode=2`

#### Scenario: Ручной свич

- **WHEN** свич вызван вручную
- **THEN** новая запись получает `mode=0`

#### Scenario: Диапазон из трёх слов

- **WHEN** словарный свич исправляет `f bp rjhj,rb` на `а из коробки`, а непосредственно перед `f` в истории находится слово `the`
- **THEN** появляется одна запись со значениями `prev = "the"`, `a = "f bp rjhj,rb"` и `b = "а из коробки"`

#### Scenario: Диапазон начинается с первого слова в истории

- **WHEN** словарный свич захватывает цепочку неоднозначных слов с первого слова в истории
- **THEN** `prev` содержит пустую строку

#### Scenario: Диапазон из одного слова

- **WHEN** свич исправляет одно слово, перед которым есть слово в истории
- **THEN** `prev` содержит это предшествующее слово
