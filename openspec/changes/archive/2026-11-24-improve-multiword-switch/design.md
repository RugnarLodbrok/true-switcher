# Design

## Context

`DictionaryAutoSwitch::comparison` уже вычисляет дельта-скор с учётом `learned`. `DictionaryAutoSwitch::decision` использует отдельные словарные скоры только для проверки старой нижней границы. Они также нужны для логирования.

`Input::switch_request` выбирает диапазон через `correction_word_count`, но заполняет `SwitchRequest.previous` словом непосредственно перед словом, запустившим свич. Поэтому при расширении диапазона `previous` указывает внутрь этого диапазона.

## Goals

Использовать результат существующего сравнения для пометки `ambiguous` на первом пробеле.

## Decisions

- Хранить `ambiguity_score_floor` как `Option<f64>` в конфигурации и в `DictionaryAutoSwitch`. Отсутствующий ключ даёт `None`. TOML не поддерживает литерал `null`.
- В `decision` вычислять нижнюю границу через `ambiguity_score_floor.unwrap_or(-comparison.current_threshold)`. Сравнивать дельта-скор с обеими границами включительно при первом пробеле. Для словарного свича использовать существующее строгое сравнение с `threshold` альтернативной раскладки.
- В `decision` проверять наличие базовых скоров после учёта `learned`. Когда оба базовых скора отсутствуют, `comparison` по-прежнему возвращает дельту `0` для диагностики, а `decision` возвращает `Keep`. При ошибке преобразования нажатий сравнение недоступно. Защиты и приоритет regex применяются в `decision` и `update_auto_switch`.
- В `Input::switch_request` один раз вычислить число слов коррекции и использовать его для выбора `words` и слова непосредственно перед этим диапазоном из `History`. Передать найденное слово в `SwitchRequest.previous`. `Statistics` уже преобразует его в текст и пишет пустую строку при `None`.

## Migration Plan

Явно заданное число применяется с новым смыслом. Для использования `-threshold` текущей раскладки удалить ключ из `config.toml`. В шаблоне установщика оставить только закомментированный пример.
