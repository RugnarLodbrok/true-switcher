# Delta spec для `auto-switch`

## ADDED Requirements

### Requirement: Роли `score` и `score_separated`

Словарный скоринг SHALL оценивать ключи через `score` и вычислять `dscore` из итоговых скоров выбранных вариантов. True Switcher SHALL вызывать `score_separated` только для вывода команды `score` и debug-лога словарного скоринга. Все прочие прямые и косвенные вызовы `score_separated` MUST NOT выполняться.

#### Scenario: Автосвич без диагностического вывода

- **WHEN** автосвич оценивает ввод при выключенном debug-логе, а команда `score` не выполняется
- **THEN** оценка ключей и расчёт `dscore` выполняются без вызовов `score_separated`

### Requirement: Составляющие выбранного варианта в диагностике

Debug-лог и команда `score` SHALL показывать собственный `dscore` слова или префикса до учёта вклада `ambiguous word chain`, базовые скоры выбранных вариантов и разность их счётчиков `learned`. Для разбиения составляющие SHALL относиться к части с минимальным итоговым скором.

#### Scenario: Диагностика показывает составляющие выбранного разбиения

- **WHEN** в текущей раскладке выбран итоговый скор `−8` (`−9 + 1`), а в альтернативной выигрывает разбиение с итоговым скором `−5` (`−7 + 2`)
- **THEN** собственный `dscore` для автосвича равен `+3`
- **AND** debug-лог строит выражение `|−9| − |−7| + 1` для того же `dscore`, а команда `score` с включённым `learned` выводит базовые скоры `−9` и `−7`, разность счётчиков `+1` и `dscore` `+3`
