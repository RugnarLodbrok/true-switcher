# Словарный автосвич на первом пробеле

## Context

`DictionaryTrie` суммирует частоты по префиксам. `Word.dictionary_prefixes` хранит по одной позиции в каждом trie на текстовое нажатие. `History` хранит завершающие пробелы отдельно. На первом пробеле `Input` уже проверяет regex и сейчас может сохранить словарный запрос от последней буквы.

## Goals / Non-Goals

Использовать одну формулу score и один порог целевого словаря для обычного префикса и для проверки на первом пробеле. Область изменения ограничена первым завершающим пробелом и существующими правилами выделения слова в `History`.

## Decisions

1. При построении `DictionaryTrie` добавлять один ASCII-пробел в конец каждого принятого слова. Разбор, фильтрация и проверка дубликатов работают по исходному полю слова. Частота записи входит в общую частоту словаря один раз. Например, узел `или` по-прежнему содержит сумму частот слов с таким префиксом, а `или␠` содержит частоту целого слова `или`.
2. Для оценки на первом пробеле взять последние позиции из `Word.dictionary_prefixes` и временно применить к каждой обычный переход `DictionaryTrie::advance` по `" "`. Оценить получившиеся позиции по существующей формуле. Это позволяет использовать обычный поиск в trie без отдельного поля конечной частоты. Стек сохраняет позиции текстовых нажатий, поэтому после удаления пробела следующий символ продолжает прежний префикс. В `Word.trailing_spaces` пробел хранится для перепечатки.
3. В `Input::update_auto_switch` сохранить приоритет regex. При отсутствии совпадения и включённом словарном автосвиче передать в словарную оценку признак первого пробела. Передать результат в `PendingSwitch::update_auto`, включая отсутствие цели. Так новая оценка заменяет запрос, который ещё ожидает коррекции. Действующие условия запуска автосвича применяются к первому пробелу.
4. При включённом `auto_switch` выводить в trace оценку первого пробела по тем же позициям, которые использует словарный выбор цели.

## Risks / Trade-offs

Терминальный пробел добавляет один узел и один переход на каждое принятое слово. Это цена повторного использования переходов и расчёта вероятностей `DictionaryTrie`.
