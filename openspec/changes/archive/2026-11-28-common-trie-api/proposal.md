# Общий API поиска в `trie1` и `trie2`

## Why

Сейчас словарный скор учитывает ключ после обрезки начальной пунктуации, а счётчик сохранённых примеров учитывает только исходный ключ. Общий вызов поиска позволяет оценивать каждый вариант в обоих trie.

## What Changes

- Для одной раскладки использовать `score(key)`. Он принимает строковый ключ и возвращает словарный скор и счётчик сохранённых примеров. Префиксный ключ — `git`, точный — `git `.
- По действующему правилу начальной пунктуации отдельно оценивать исходный ключ и непустой остаток. Выбирать максимум отдельно для скора и для счётчика.
- Удалить стек позиций `trie1` из `Word` и начинать каждый поиск в обоих trie от корня.

## Capabilities

### Modified Capabilities

- `auto-switch` — учитывать обрезанный ключ в поправке по сохранённым примерам.

## Impact

Изменение затрагивает общий расчёт дельта-скора для автосвича и `score` CLI, поиск в `LearnedRules` и хранение истории слова.
