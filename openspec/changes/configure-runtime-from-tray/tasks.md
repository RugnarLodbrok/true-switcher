# Задачи

## 1. Настройки во время работы

- [ ] 1.1 Инициализировать четыре runtime-флага из `Configuration` и добавить события их изменения. В тестах обработки ввода проверить, что словарный автосвитч и паттерн-свитч включаются и выключаются независимо, а выключение отменяет ожидающую коррекцию соответствующего способа.
- [ ] 1.2 Подключить флаги звука к созданию коррекции и запускать worker `Sound` по первому запросу. Проверить, что оба вида звука можно независимо включать после запуска с обоими выключенными флагами.

## 2. Сохранение конфигурации

- [ ] 2.1 Подключить `toml_edit` и сохранить загруженный документ рядом с `Configuration`. В тестах записи проверить сохранение форматирования, комментариев на изменённых строках и остальных полей, добавление отсутствующих ключей, полную замену вручную изменённого файла и создание удалённого файла.

## 3. Меню трея

- [ ] 3.1 Добавить четыре переключателя в D-Bus меню и обновлять их свойства по применённым значениям. Проверить, что при трёх и более раскладках выключенный автосвитч недоступен с причиной в подписи, а включённый можно выключить.
- [ ] 3.2 Подключить «Записать в конфиг» к записи согласованного snapshot. Проверить сценарии через меню: переключатель сам по себе не меняет файл, `Reload` сбрасывает несохранённые изменения и загружает сохранённые, а ошибка записи не меняет runtime-флаги и не вызывает уведомление.
