# Установка KWin-скрипта

## Why

Передачу событий фокуса требуется настраивать при установке поддерживаемой версии Bazzite KDE.

## What Changes

Устанавливать и включать true-switcher-focus для поддерживаемого окружения.

## Capabilities

### Modified Capabilities

- `installation` — Установка KWin-скрипта.

## Impact

Исходная [задача №10](../../../doc/tasks/10.md).
