## ADDED Requirements

### Requirement: Режим без захвата клавиатуры

True Switcher SHALL допускать прохождение нового физического текста во время экспериментальной коррекции без grab.

#### Scenario: Режим без захвата клавиатуры

- **WHEN** пользователь вводит обычный символ во время синтетического ввода и других причин отмены нет
- **THEN** коррекция продолжается, прошедший в приложение ввод не откатывается и не воспроизводится повторно
