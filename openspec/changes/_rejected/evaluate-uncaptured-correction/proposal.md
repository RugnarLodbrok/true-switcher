# Режим без захвата клавиатуры

## Why

Коррекция без `grab` уже включена. Пользователь может продолжать печатать во время исправления, и его ввод может смешаться с синтетическим.

## What Changes

По результатам использования решить, оставить ли этот режим включённым по умолчанию.

## Capabilities

### Modified Capabilities

- `layout-correction` — Режим без захвата клавиатуры.
