## MODIFIED Requirements

### Requirement: Конфигурация словарей

True Switcher SHALL принимать одну или две записи dict с разными целями, относительными путями и конечными положительными порогами.

#### Scenario: Конфигурация словарей

- **WHEN** настроен один словарь и его цель не активна
- **THEN** запрос возникает при строгом превышении порога оценкой по позиционным вероятностям, если целевой префикс существует
