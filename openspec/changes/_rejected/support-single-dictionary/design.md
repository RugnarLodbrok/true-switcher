# Конфигурация словарей

Статус — отложена. После [задачи 27.1](../../../doc/tasks/27.1.md) конфигурация с одним словарём считается ошибкой. Эта задача добавляет поддержку одной записи `[[dict]]`.

## Расчёт оценки

Свич возможен только на `target` настроенного словаря. Пусть `n` — длина введённого префикса после приведения к lowercase, а `cᵢ` — его символ на позиции `i`, считая с единицы. Каждое слово входит в суммы со своей частотой из словаря.

```text
score = log₂(P_dict(prefix) / (P₁(c₁) × … × Pₙ(cₙ)))
P_dict(prefix) = F(prefix) / Tₙ
```

- `F(prefix)` — сумма частот слов, начинающихся с введённого префикса.
- `Tₙ` — сумма частот слов длиной хотя бы `n` символов.
- `Pᵢ(cᵢ)` — сумма частот слов с символом `cᵢ` на позиции `i`, делённая на `Tᵢ`. Произведение этих долей даёт ожидаемую частоту префикса при независимом выборе символов по позициям.

Например, пусть 4% вхождений слов длиной хотя бы два символа начинаются с `th`. Если 10% всех вхождений начинаются с `t`, а у 5% вхождений длиной хотя бы два символа на втором месте стоит `h`, то при независимом выборе символов ожидаемая доля равна `10% × 5% = 0,5%`. Для `t` получаем `log₂(10% / 10%) = 0` бит, для `th` — `log₂(4% / 0,5%) = 3` бита.

Если целевой префикс отсутствует, словарного запроса нет. Это включает неизвестный символ на данной позиции и префикс длиннее любого словарного слова. В этих случаях вычислять отношение не требуется.

Словарный запрос возникает при `score > threshold` единственного словаря.

## Критерии готовности

- Тест с одним словарём показывает ноль бит на первом известном символе и свич на последующем символе характерного сочетания. При уже активной целевой раскладке словарного запроса нет.
- Для одного словаря тесты покрывают отсутствие целевого префикса, включая неизвестный символ на позиции и превышение максимальной длины слова.
