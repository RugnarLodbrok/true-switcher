# Интерактивный словарный скоринг

## Why

Для обсуждения, составления примеров для документации удобно иметь возможность считать реальные скоры. Сейчас словарный скоринг доступен через debug-лог запущенного свитчера. При переборе слов удобнее загрузить словари один раз и отправлять запросы в одну сессию.

## What Changes

- Добавить команду `true-switcher score`. Она загружает два настроенных словаря один раз на запуск, затем читает запросы из stdin до EOF.
- Принимать одну строку вида `ru us куищще`. Для каждого префикса и первого пробела выводить текст в обеих раскладках, базовые скоры, поправку `trie2`, `dscore` и сравнение с `threshold` целевого словаря.
- Добавить флаг `-l, --learned-rules`, который включает поправку `trie2` и колонку `Learned`. По умолчанию поправка выключена. Добавить `-t, --threshold` для переопределения порога на сессию.
- Показывать все проблемные позиции слова в одной диагностике. Неоднозначные нажатия выбирать индексами, добавленными к запросу через пробел слева направо.
- Использовать один формат запросов для терминала, файла и pipe. При чтении с терминала показывать приглашение `> `, при чтении из файла или pipe завершать каждый ответ строкой `END OK` или `END ERROR`. Скоринг выполняется отдельно от службы ввода и использует тот же расчёт, что и свитчер.
- Когда stdin и stderr подключены к терминалу, редактировать строку ввода и листать историю запросов клавишами `↑` и `↓`. Хранить историю в памяти до завершения `score`.
- Показывать ход загрузки словарей в одной обновляемой строке, когда stdin и stderr подключены к терминалу. При чтении файла показывать процент, при построении индекса — spinner.
- Использовать английский язык для всего интерфейса команды.
- Генерировать справку `score -h` и `score --help` из описания аргументов. Дополнить её форматом запросов, примерами и кодами выхода.

## Impact

Точка входа в `main`, зависимости `clap` для аргументов и справки и `rustline` для редактора строки, загрузка конфигурации и XKB-раскладок, повторное использование `History`, `DictionaryAutoSwitch` и `LearnedRules`.
