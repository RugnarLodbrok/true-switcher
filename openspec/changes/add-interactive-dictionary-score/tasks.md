- [x] 2.2 Подключить `true-switcher score` в `main`, разбор аргументов и генерацию справки через `clap`. Проверить тестами короткие и длинные ключи, значения по умолчанию, английскую справку с кодом `0` без конфигурации и ошибки аргументов в stderr с кодом `2`.

Проверить приглашение `> ` при терминальном stdin и перенаправленном stdout, а также маркеры при вводе из файла с выводом в терминал.
- [x] 2.4 Определять код выхода при EOF по типу stdin и результатам запросов. Проверить тестами завершение с кодом `1` после обработки файла или pipe с ошибочной строкой и с кодом `0` при штатном выходе из интерактивной сессии после ошибки запроса.
