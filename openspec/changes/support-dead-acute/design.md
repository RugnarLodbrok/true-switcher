# Защита при dead key

Ниже приведены примеры из исходной задачи. В текущем коде обнаруженная dead key блокирует коррекцию слова. Примеры описывают ошибки, которых должна избежать реализация с поддержкой композиции.

Статус: черновик.

## Цель

Поддержать ввод с `dead_acute` при ручном и автоматическом исправлении раскладки.

## Проблема

В `us(intl)` клавиша апострофа без Shift даёт `dead_acute`. В приложении с поддержкой композиции после неё и клавиши `e` появляется один символ `é`. `History` сохраняет два `WordStroke`. Backspace удаляет одну запись из `History`, а коррекция отправляет по одному Backspace на каждую сохранённую запись. Для составного ввода оба действия могут нарушить соответствие между историей и текстом приложения.

Текущий конвертер XKB преобразует нажатия по отдельности. Для `dead_acute` он возвращает `NoTextForKey` и прерывает преобразование всего слова. Та же физическая клавиша в `ru` даёт `э`, поэтому преобразование тех же нажатий в `ru` может пройти успешно.

## Примеры

- **Обычный Backspace.** В `us(intl)` пользователь вводит `café`. В поле четыре символа, в `History` пять нажатий. Один Backspace оставляет `caf` в поле, но в `History` остаются `c`, `a`, `f` и `dead_acute`, потому что удалилось только нажатие `e`.
- **Ручное исправление.** В поле `un café`, текущее слово в `History` содержит пять нажатий. При ручной коррекции True Switcher отправляет пять Backspace. Четыре стирают `café`, пятый стирает пробел перед ним.
- **Автосвич по regex.** В `us(intl)` нажатия апострофа и `e` дают в поле `é`. Regex с целью `ru` проверяет те же нажатия как `эу`. При совпадении возможна коррекция с двумя Backspace за один символ. Ошибка `NoTextForKey` в исходной раскладке этому не препятствует, поскольку regex преобразует нажатия в целевую раскладку.
- **Проектируемый словарный автосвич.** В начале `éclair` после `dead_acute` приложение ещё ждёт следующее нажатие, а преобразование в `ru` уже даёт `э`. Если присвоить `NoTextForKey` оценку `0`, при подходящих порогах словарь может выбрать `ru` до нажатия `e`. [Задача 27](../../../doc/tasks/27.md)
