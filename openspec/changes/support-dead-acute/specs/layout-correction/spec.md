## MODIFIED Requirements

### Requirement: Защита при dead key

True Switcher SHALL учитывать композицию dead_acute при ручной и автоматической коррекции, сохраняя защиту для неподдержанных dead keys.

#### Scenario: Защита при dead key

- **WHEN** в поле введено un café и пользователь исправляет последнее слово
- **THEN** удаляется только café, предшествующий пробел сохраняется и исходные нажатия воспроизводятся в целевой раскладке
