# Tasks

## 1. Словарный скоринг

- [ ] 1.1 Добавить поиск по одному остатку после обрезки обоих краёв в каждой раскладке. Использовать точный ключ для остатка при срезе конечной пунктуации или на первом пробеле. Обновить комментарий к `punctuation` в `installer/config.example.toml`. Покрыть тестами варианты с одним и двумя краями, пустой остаток, пользовательский regex, точный поиск до и после первого пробела и точку, которая становится внутренней при продолжении набора. Выполнить `cargo test --bin true-switcher`, включая существующие тесты защиты от автосвича и скоринга начальной пунктуации.
- [ ] 1.2 Добавить третий вариант словарного скора, когда токен делится на части только в текущей раскладке. Покрыть тестами точные ключи частей до последней, режимы поиска последней части, минимум скоров, отсутствующий ключ и максимум из трёх вариантов при расчёте дельта-скора. Выполнить `cargo test --bin true-switcher`.
