# Словарная оценка токенов с конечной пунктуацией

## Context

`DictionaryAutoSwitch` хранит путь полного токена отдельно для каждой раскладки. Для оценки остатка он переводит нажатия в текст нужной раскладки и ищет ключ от корня словарного `trie`. `LearnedRules` вычисляет счётчик по нажатиям полного токена. Оба trie используют `WORD_END` (один пробел) для перехода к точному ключу.

## Goals / Non-Goals

Применять обрезку к поисковому ключу на этапе скоринга. При обучении индексировать и сохранять полный токен. Принимать решение о блокировке по полному токену текущей раскладки и при автосвиче перепечатывать полный токен.

## Decisions

- Компилировать тот же `punctuation` для поиска непустого совпадения на конце токена, с якорем `\z` после всей группы regex. Начальный и конечный шаблоны применять к исходному тексту в оцениваемой раскладке, затем брать общий остаток между совпадениями. Совпадения нулевой длины игнорируются. При пустом остатке, в том числе при пересечении совпадений, оценивается полный токен.
- Вычислять вариант с обрезкой один раз на раскладку и использовать его в обоих trie. Для остатка использовать точный поиск, когда удалён хотя бы один конечный знак или введён первый завершающий пробел. В обоих случаях к остатку добавляется один `WORD_END`.
- Выбирать максимумы независимо. Словарный скор может прийти из полного ключа, а счётчик сохранённых примеров — из обрезанного. Подставлять выбранный счётчик в существующий расчёт базового скора и дельта-скора.
- Если только текст в текущей раскладке делится по внутренним совпадениям `punctuation` на две или более непустые части, добавить третий вариант в `trie1`. Оценить все части до последней по точному ключу с `WORD_END`. Последнюю оценить по точному ключу при конечной пунктуации или первом пробеле, иначе по префиксу. Пропустить пустые части. Скор разбитого варианта равен минимуму скоров частей, включая `−∞` для отсутствующего ключа.
- Выбрать для текущей раскладки максимум из скоров полного токена, обрезанного токена и разбитого варианта. Вычесть этот максимум из словарного скора альтернативной раскладки и затем учесть существующую поправку `trie2`. При несовпадающем разбиении скоры частей вычисляются внутри раскладки, а дельта-скор — для токена целиком.

## Risks / Trade-offs

Конечный знак может запустить словарный автосвич до первого пробела. При следующем скоринге край определяется заново. Например, после допечатывания `git.hub` точка становится внутренней.
