# Spec Delta

## MODIFIED Requirements

### Requirement: Синтетический ввод

True Switcher SHALL воспроизводить физические клавиши через виртуальную клавиатуру после успешной смены раскладки. Текстовые клавиши нумпада, сохранённые в истории слова, SHALL учитываться при удалении текста и воспроизводиться в исходном порядке вместе с остальными клавишами.

#### Scenario: Синтетический ввод

- **WHEN** на этапе удаления произошла ошибка или поступила отмена
- **THEN** программа не начинает повторный ввод слова

#### Scenario: Ручная коррекция слова с Numpad Divide

- **WHEN** пользователь вводит `гы/кг ` в RU с `/` на клавише Numpad Divide и запускает ручную коррекцию в US
- **THEN** True Switcher удаляет пять символов и завершающий пробел и вводит `us/ru `
