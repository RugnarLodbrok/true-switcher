# Возврат раскладки после слова

## Назначение

Добавить группу паттернов `switchback`: после завершения слова, исправленного автосвичем, возвращать раскладку, действовавшую до автосвича. Уже введённый текст слова при возврате раскладки не изменять.

## Базовый сценарий

1. При вводе слова произошёл автосвич.
2. Пользователь завершил слово.
3. Слово совпало с одним из паттернов `switchback`.
4. Программа вернула раскладку, действовавшую до автосвича. Само слово осталось без изменений.

Если на этом слове автосвича не было или слово не совпало с паттерном, `switchback` не переключает раскладку.

## Ограничения и связанные задачи

- Сценарии с более чем двумя раскладками для `switchback` не поддерживаются. Поведение при такой конфигурации нужно определить.
- Правила автосвича описаны в [задаче 19](../../../doc/tasks/19.md). В текущем режиме исправленное слово защищено от следующего автосвича.
