## ADDED Requirements

### Requirement: Установка для нескольких пользователей

True Switcher SHALL поддерживать установку для нескольких пользователей одной системы.

#### Scenario: Установка для нескольких пользователей

- **WHEN** два пользователя используют True Switcher на одном компьютере
- **THEN** каждый запускает службу в своём сеансе с собственными настройками
