# Design

## Context

Сейчас `WordStroke` хранит физический `Stroke` и фактическую на момент ввода раскладку. `correct_words` обслуживает ручной, словарный и паттерный свич. Текущий путь считает каждую запись за один Backspace и воспроизводит все сохранённые нажатия.

## Goals / Non-Goals

- Единые правила синтетического ввода для всех режимов коррекции.
- Вне scope остаются выбор цели автосвича, классификация поддерживаемых клавиш и правила dead keys.

## Decisions

- Сохранять полную последовательность `WordStroke`. Результат `NoTextForKey` зависит от раскладки, поэтому один и тот же `Stroke` может давать текст при повторном вводе или при следующей коррекции.
- Передать в общий путь синтетического ввода целевую раскладку. Для ручного запроса использовать раскладку, уже полученную через `kde::next_layout`, а для автоматического — цель из запроса.
- До первого Backspace подготовить удаление и повторный ввод по сохранённым `WordStroke`. Для каждого нажатия проверить `NoTextForKey` в его сохранённой раскладке для удаления и в целевой для повторного ввода. Использовать существующее преобразование XKB с учётом Shift. Пробелы и порядок оставшихся нажатий сохраняются.
- Считать специальным случаем только явный `NoTextForKey`. Для неизвестной раскладки и других результатов преобразования сохранить действующее поведение соответствующего пути. Правила отмены и предварительная проверка dead keys продолжают действовать.
- Для успешно исправленного диапазона сохранить все `Stroke` с целевой раскладкой, включая пропущенные при повторном вводе. Следующая коррекция использует эту раскладку для подсчёта Backspace.

## Risks / Trade-offs

- При выборе словарного автосвича действующее преобразование может завершиться с `NoTextForKey` и прекратить сравнение раскладок. Новое правило применяется к синтетическому вводу после выбора коррекции.
- Change `support-numpad-text-keys` добавляет клавиши, на которых проявляется этот случай. Общий путь можно тестировать с любой поддерживаемой клавишей, для которой тестовая XKB-карта возвращает `NoTextForKey`.
