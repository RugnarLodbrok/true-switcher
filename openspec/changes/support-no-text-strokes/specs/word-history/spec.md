# Spec Delta

## ADDED Requirements

### Requirement: Сохранение нажатий без текстового результата

True Switcher SHALL сохранять `Stroke` поддерживаемой текстовой клавиши и его раскладку при `NoTextForKey`.

#### Scenario: Нажатие без символа между буквами

- **WHEN** между двумя буквами пользователь нажимает поддерживаемую текстовую клавишу, для которой XKB возвращает `NoTextForKey` в текущей раскладке
- **THEN** история сохраняет все три нажатия в исходном порядке вместе с их раскладками

#### Scenario: Повторная коррекция

- **WHEN** коррекция завершилась успешно и целевая раскладка вернула `NoTextForKey` для одного из сохранённых нажатий
- **THEN** история сохраняет это нажатие с целевой раскладкой для следующей коррекции
