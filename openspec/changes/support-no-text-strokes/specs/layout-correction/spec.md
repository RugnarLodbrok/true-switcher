# Spec Delta

## ADDED Requirements

### Requirement: Синтетический ввод при NoTextForKey

При ручной, словарной и паттерной коррекции True Switcher SHALL исключать из подсчёта Backspace нажатия с `NoTextForKey` в сохранённой раскладке каждого нажатия. При повторном вводе True Switcher SHALL пропускать нажатия с `NoTextForKey` в целевой раскладке и воспроизводить остальные в исходном порядке.

#### Scenario: Символ появляется в целевой раскладке

- **WHEN** из трёх сохранённых нажатий среднее вернуло `NoTextForKey` в исходной раскладке, а в целевой все три нажатия дают текст
- **THEN** коррекция отправляет два Backspace и воспроизводит три нажатия

#### Scenario: Символ отсутствует в целевой раскладке

- **WHEN** три сохранённых нажатия дали текст в исходной раскладке, а в целевой среднее возвращает `NoTextForKey`
- **THEN** коррекция отправляет три Backspace и воспроизводит первое и третье нажатия

#### Scenario: Нажатие без текста в обеих раскладках

- **WHEN** в диапазоне коррекции есть нажатие с `NoTextForKey` в исходной и целевой раскладках
- **THEN** оно даёт ноль Backspace и пропускается при повторном вводе
- **AND** завершающие пробелы удаляются и воспроизводятся по общему правилу
